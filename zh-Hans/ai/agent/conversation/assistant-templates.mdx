智能体模板让你从已经准备好的角色开始工作。导入会创建自己的智能体，可调整名称、模型和工作方式。想直接与已有专家协作时，使用“数字专家”；想部署整套业务方案时，使用“应用”。概念区别见[插件、应用与智能体模板](/zh-Hans/ai/plugin/extension-model)。

## 发现与比较

在 Web 的探索入口或 Desktop 的“发现与添加”中打开“智能体模板”。来源按以下顺序排列：**智能体插件 → Xpert 插件 → 系统内置 → 共享模板**。选择来源后，分类及数量显示该来源的可见模板；还可以按名称、场景和能力搜索。

目录分批加载，已出现的模板可以先查看。数量受当前组织、访问权和语言中的可用内容影响，加载完成前还会变化。

点击卡片查看详情。详情包括职责与工作方式、初始知识、技能、例行任务及集成要求。“使用模板”可以直接进入配置。

## 导入自己的智能体

1. 在详情中选择“导入为智能体”。Web 也可以选择“在桌面客户端中打开”，继续在 Desktop 预览和导入。
2. 选择你有编辑权限的工作空间，确认名称、头像和所需模型。
3. 查看依赖和运行要求。缺少必须的插件或不支持的能力时，先按提示处理；账号与偏好可在允许的后续配置步骤完成。
4. 开始安装，查看创建、依赖安装、发布和初始化进度。
5. 打开创建的智能体，完成首次使用配置并核对首个业务结果。

同一次安装失败或中断时，先刷新状态，再使用原记录的重试入口。刷新页面或重开客户端不会要求你重新创建一份。需要另一个独立实例时，再发起新的安装。

如果来源版本在恢复前发生变化，系统会要求重新检查，不会在你未查看的情况下继续安装另一份内容。

## 首次配置与外部连接

根据角色需要，填写时区、语言和业务偏好。系统保存已完成的步骤，中断后可以继续。首次使用的完成标准由模板定义，通常包含实际台账、摘要或草稿。

集成页面列出必需和可选服务。选择有权使用的已有连接，或由有权管理连接的人完成授权。授权必须在目标环境进行，模板不会携带发布者的账号、密码或令牌。

缺失、过期或权限不足的连接会提示处理。可选服务可以跳过，相关工具随之不可用；必需服务未就绪时，相应业务无法完成。平台已安装插件、账号已授权和业务已执行成功是不同状态。

需要对外发送、修改或删除的操作可能进入审批。核对操作内容后作出决定；拒绝后不执行该工具操作。

## 文件与持续工作

模板可以准备工作目录、初始说明和空台账。初始化只创建缺少的文件，不覆盖已经录入的业务记录。角色应在执行时读取现有记录并持续更新，而不是把对话记录当作唯一业务台账。

模板会说明文件是按用户隔离还是由获准协作者共享。已有文件权限和业务访问规则仍然有效。升级模板不会自动替换你的业务文件。

## 启用例行任务

例行任务默认暂停。打开任务配置，确认执行内容、时间、时区和结果位置后再启用。也可以随时暂停，避免后续自动运行。

服务端任务可以在 Web 和 Desktop 关闭后继续执行；依赖本机独有能力的任务不能直接转为服务端后台运行。当前提供定时任务，事件触发要求会标记为尚不可用。

在活动记录查看运行结果、失败原因或待审批事项。未读状态按你的账号保存，页面会定期刷新。这些是应用内记录，不意味着会发送邮件、短信或系统推送。

## 分享自己的模板

有权维护智能体的用户可以检查发布预览，再选择组织分享或公开分享。公开内容仍要求接收者登录平台。

模板分享不携带你的对话、业务文件、账号绑定、个人偏好或任务启用状态。发布前仍需检查指令等自由文本中的敏感内容；不支持迁移的配置会显示阻止原因。

接收者查看详情后自行导入并配置账号。撤销分享会停止后续发现和导入，不删除接收者已经创建的智能体。分享链接也不会自动执行安装。

## 更新已有智能体

出现新模板版本时，打开升级预览，查看上游变更与本地修改。对于冲突项明确选择保留或采用，然后保存草稿并发布。

升级保留智能体身份、对话、业务数据和兼容的配置。新增例行任务保持暂停。数据范围或已有任务定义等不兼容时，系统会要求先处理，不能直接覆盖。

安装操作与升级操作都应从已有记录恢复。支持的配置回退可以恢复之前的定义，但不撤销已经发送的消息、外部写入或业务数据修改。

## 常见问题

**为什么 Office Ops 标为智能体插件，而不是系统内置？** 它由 Agent Plugin 文件包提供，模板来源与界面中显示的角色名称无关。

**为什么翻译了介绍，技能内容仍是英文？** 展示内容跟随界面语言；内部技能、执行指令及业务文件不自动翻译。

**为什么已安装仍提示配置？** 安装只完成模板与指定资源的创建；模型、外部账号、偏好、发布和任务启用有各自的状态。

**为什么我看不到目标工作空间？** 确认当前组织及账号，并检查该空间的编辑权限。能够使用已发布智能体不代表可以编辑它所在的空间。

**连接器是否都可以直接使用？** 取决于目标环境已安装的服务能力、账号授权和权限。Notion、Slack、Linear、Google Sheets、Gmail、Calendar 等服务需要各自配置并验证真实业务操作。
