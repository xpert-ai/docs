Live Dashboard（实时看板，也称 Artifacts Dashboard）把业务需求转成可以保存、继续修改和刷新数据的看板。你可以选择标准图表，也可以让助理生成带有自定义布局、配色和交互的 HTML 页面。看板保存为同一份 Artifact，后续可以继续编辑草稿、发布正式版本和分享。

例如，描述“按月查看各区域的季度净销售额，顶部放总额，左侧放趋势，右侧放明细，并支持区域筛选”，助理会先检查可用数据和指标口径，再生成看板草稿。

## 适合哪些业务场景

- **经营与指标跟踪**：将总额、趋势和明细组织到同一页面，用区域、时间等筛选项查看业务范围。
- **文件分析简报**：处理授权工作区中的文件，按明确口径清洗、汇总，再展示结果。
- **持续评审与团队查看**：在同一份看板上调整样式或分析要求，人工定稿后分享正式版本。

## 一份看板的使用过程

1. **创建**：选择已配置看板能力的助理，说明数据来源、指标、时间范围和页面要求。
2. **查看**：助理保存成功后，点击对话资源卡片的“打开”，进入 ChatKit 工作台中的“实时看板”。
3. **修改**：打开目标看板，继续用自然语言调整页面或业务要求。修改保存在同一看板的草稿中。
4. **定稿**：检查数据与交互后，在工作台点击“发布草稿”并确认，形成正式版本。
5. **分享**：为正式版本开启组织内只读分享，成员可筛选和刷新自己有权查看的数据。

对话中的资源卡片提供返回入口；点击“打开”会直接进入 ChatKit 自己的工作台。团队分享链接则打开独立看板页，操作栏收起为半透明按钮，悬停或点击后展开，尽量保留页面观看空间。

## 可以生成什么

| 方式 | 适合的需求 |
| --- | --- |
| 标准图表 | 柱形、折线、面积、饼图、散点图和数据表格 |
| 自定义页面 | 自由布局的经营简报、指标概览、趋势和明细组合；可使用 ECharts |
| 文件或脚本处理结果 | 根据授权文件或来源进行 Python/JavaScript 处理后展示 |

自定义页面可改变布局和样式，但仍从已配置数据来源取数。它不能自行连接任意网站、加载 CDN 脚本或读取平台凭据。Three.js 核心库可用，其 3D 页面仍需单独确认浏览器和 GPU 兼容性。

## “实时”与“版本”的含义

- 打开、筛选和刷新会重新查询数据。页面中显示的取数时间不一定是业务数据最后修改时间。
- 自定义 HTML 页面可以包含定时刷新；目前没有所有看板通用的自动刷新开关，也没有保证实时推送的数据订阅。
- 草稿和正式版本保存页面定义、指标配置和图库依赖，不保存当时查询出的全部数据。
- 打开历史正式版本会使用旧版定义查询当前有权访问的数据，不能用它替代历史数据快照。

当前团队分享只支持已发布的只读版本。工作草稿由创建者管理，Workspace 脚本来源的看板暂不支持团队分享。

- [智能体对话](/zh-Hans/ai/agent/conversation/conversation)负责表达需求和持续修改，实时看板负责保存、查看和刷新分析页面。
- [Artifacts](/zh-Hans/ai/agent/artifacts/index)提供结果的身份、草稿、版本和访问管理；本栏目介绍看板的具体使用流程。
- [本体工作台与资源对话](/zh-Hans/data/features/agent-execution/workbench-and-chatkit)帮助理解 data-xpert 的资源上下文。看板可使用已配置的本体来源，权限和只读操作范围仍由来源控制。
