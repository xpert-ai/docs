## 当前来源

| 来源 | 使用方式 | 注意事项 |
| --- | --- | --- |
| PostgreSQL | 查询已配置数据库 | 需要来源访问权和只读查询能力 |
| MySQL、Doris | 查询已配置数据库和表 | 当前 Doris 已验收内置 Catalog；不代表其他兼容数据库均已支持 |
| data-xpert 本体 | 使用已发布资源和允许的只读操作 | 需要正确的身份连接、资源绑定和访问者策略 |
| MCP | 调用平台已有连接中获准的只读工具 | 需要连接所在工作区权限；工具契约变化或撤销后拒绝查询 |
| REST/JSON | 调用已配置 OpenAPI 连接中的只读操作 | 复用连接认证；仅允许已批准的接口、参数和分页规则 |
| CSV、JSON、XLSX | 直接查询已登记的工作区文件，筛选、分组和汇总 | 需要文件访问权及明确字段定义；不执行 Excel 公式 |
| Workspace Python/JavaScript | 处理授权文件，或组合已声明来源的查询结果 | 当前为私人脚本定义，暂不支持团队分享 |

看板只列出当前有权访问且有适配能力的来源。分享看板不会自动授予数据库、本体资源或文件的访问权。

data-xpert 可通过其已发布的本体适配器提供不同资源，具体字段和操作由资源定义决定。不能据此假设看板可以直接访问任意 REST 地址或所有语义模型。

## 使用文件和脚本

对于常规筛选、分组、求和、计数、最小值和最大值，优先使用已登记的 CSV/JSON/XLSX 文件数据源，无需编写脚本。管理员配置文件位置、格式、字段类型和业务口径；助理选择来源和查询参数。文件路径不能由页面或筛选项替换。

每次刷新都会重新读取源文件。更新同一路径下的内容后，刷新即可取得新结果；文件配置或字段契约变化时，需要重新发现并验证查询。XLSX 不执行公式，默认拒绝公式单元格；明确配置使用缓存值时，只读取文件里已有的计算结果，不保证公式已重新计算。

需要复杂清洗或跨来源组合时，再使用 Workspace Python/JavaScript。将输入文件及指标说明放到授权工作区，告诉助理准确文件名和处理规则。

刷新会重新执行脚本，并读取本次有权访问的输入。保存定义时可以固定脚本代码，或配置每次读取当前代码；这与刷新输入数据是不同的选择。代码固定不会让文件中的业务数据也固定。

当前脚本使用标准库和 UTF-8 文件，不自动安装 pandas 或 npm 包。复杂处理或较大输入可能超过执行限制，需要缩小范围或调整来源查询。

## 筛选与刷新

- 筛选项来自看板定义及查询结果；选择后会重新查询。
- 手动刷新保留当前筛选；关闭并重开恢复定义中的默认筛选。
- 自定义页面可以按要求实现定时刷新，但不是所有看板都自动具备定时器。
- 取数时间更新说明发生了新的查询，不证明上游业务数据已经变化。
- 部分结果、截断提示和空结果需要结合业务范围判断，不应直接解读为全量总额或零业务量。

数据来源、页面和用户权限都可能影响刷新结果。历史版本或固定分享链接仍按当前权限查询，不能绕过已撤销的访问权。

## 管理员配置提示

管理员需要部署 Live Dashboard 和对应来源插件，配置对应数据库驱动、本体/MCP/OpenAPI 连接或文件目录，并给助理启用看板工具及相应技能。HTML 保存检查需要浏览器运行环境；脚本另需受限 Python/JavaScript 运行环境。只启用工作台视图不足以让助理获得工具。

升级看板插件后，还需更新助理已安装的看板技能并核对内容；仅更新插件不会替换已有技能副本。

当前平台单次查询最多 30 秒、1,000 行和 2 MB 结果。声明式文件输入最多 8 MB、50,000 行；超限会失败，不会静默只统计前一部分。脚本另有文件与调用限制。建议先让来源完成必要聚合，再展示图表；不要通过重复查询拼接被截断的数据并声称完整。

无法完成查询时，参见[常见问题](./troubleshooting)。
