---
title: "看板常见问题"
description: "排查生成、保存、图表、筛选、版本和团队分享问题。"
---

## 助理没有生成看板

请先确认使用的是已启用实时看板工具的助理。工作台能看到看板入口，不代表本轮对话已启用工具。数据源也必须已配置并对当前用户可见。

如果助理询问指标定义、时间范围或目标来源，补充业务说明后继续。不要用凭据代替来源配置，也不要要求助理猜测缺失字段。

## 写了 HTML，为什么没有保存结果

编写文件只是生成过程的一步。HTML 必须通过页面检查并保存为看板草稿。让助理继续检查错误并完成保存，核对实际草稿状态，而不是只看文字回复。

“已保存草稿”不代表产生新的正式版本。正式版本必须由你在工作台点击“发布草稿”并确认。若卡片未显示，但保存成功，可使用实时看板的搜索选择器重新打开。

## 图表没有显示，或筛选后旧数据仍在

先检查是否有数据、单位和分组是否合理。自定义页面可能存在图表尺寸、字段映射或更新逻辑问题；可以让助理修复当前看板，同时保留指标和来源。

建议明确要求验证“全部 → 一个区域 → 另一区域 → 全部”，让总额、图表系列和明细保持一致。数据查询成功不代表页面绘制正确。

HTML 中不能直接加载 ECharts CDN。要求助理使用系统已提供的图库即可；无需发送外部脚本链接。

## 刷新没有变化，或数据不完整

刷新保留当前筛选并重新查询；来源数据未变化时，数值可以保持不变。需要检查上游更新状态时，请区分取数时间与业务更新时间。

出现部分或截断提示时，缩小查询范围或让来源先聚合。空结果也可能由筛选、权限或日期范围导致，不能直接当作零业务量。

定时刷新只在页面已经实现计时器时生效，不是默认后台任务。关闭页面后不应期待它继续更新。

## 草稿卡片的修订号与打开内容不同

旧消息保留当时的保存状态，打开草稿卡片时会读取当前已保存草稿。查看某次正式定稿，请使用版本菜单或明确指向该历史版本的卡片。当前不提供中间草稿历史恢复。

保存或发布冲突时，重新读取最新内容并处理差异。不要重复要求覆盖，或另建同名看板掩盖冲突。

## 无法分享或访问独立页

| 现象 | 处理 |
| --- | --- |
| 只有草稿，无法开启分享 | 先检查并人工发布正式版本 |
| 提示私有脚本或文件依赖 | 当前 Workspace 脚本看板不能团队共享 |
| 成员打开后无法查询 | 检查组织成员身份、数据库或本体资源访问权 |
| 新页面没有打开 | 检查浏览器是否阻止弹窗；仍可复制链接在新标签中打开 |
| 登录后仍无法查看 | 请管理员检查正常登录回跳和平台、插件的配套配置 |
| 提示链接失效或版本变化 | 向创建者索取当前链接，或重新打开最新页面 |

分享不会让成员获得创建者的来源权限。修改分享策略会使旧链接失效；撤销权限后不应继续访问。

## 生成或修改时反复调用工具

助理会在编写页面前检查来源预览和适用的筛选项；修改已有 HTML 看板时，会先读取准备好的编辑副本。一次工具失败不一定需要重新生成看板；应保留当前目标，让助理按错误提示修复并取得新的草稿保存回执。

如果仍反复失败，请反馈本轮错误提示和修改要求。管理员可以区分筛选验证缺失、文件编辑失败、页面检查失败与并发冲突。自动修复不能跳过权限和查询范围检查，也不保证所有模型都能一次生成成功。

## 向管理员反馈什么

提供操作步骤、看板名称、使用的来源、草稿或正式版本状态、筛选值、错误提示，以及问题发生时间。避免在截图或对话中粘贴数据库密码、接口令牌或完整敏感数据。管理员可据此检查工具调用、保存记录、来源权限和运行环境。
