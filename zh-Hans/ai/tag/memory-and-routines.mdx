群记忆和例行任务让 Xpert Tag 从“被动问答机器人”变成“长期参与团队协作的数字专家”。当前 Xpert 已有长期记忆、文件记忆、技能、Schedule Trigger 和定时任务工具等基础能力，但群级记忆与自然语言 routine 还未产品化。

## 群记忆

群记忆用于保存对该群长期有效的规则、事实、偏好和决策。

| 记忆类型 | 示例 | 状态 |
| --- | --- | --- |
| 群规则 | “回复先给结论，再给依据。” | 未实现（规划） |
| 输出格式 | “日报必须包含进展、风险、阻塞、下一步。” | 未实现（规划） |
| 项目事实 | “当前项目客户是华域三电。” | 未实现（规划） |
| 决策记录 | “报价口径按 2000/人天计算。” | 未实现（规划） |
| 禁止事项 | “不要在客户群展示内部产品代号。” | 未实现（规划） |
| 工具偏好 | “代码相关任务默认使用 acme/data-pipeline 仓库。” | 未实现（规划） |

目标交互：

```text
@Xpert 记住：这个群的日报输出用表格，必须包含风险和负责人。
@Xpert 你记得这个群有哪些规则？
@Xpert 删除关于旧报价流程的记忆。
@Xpert 修正：发布窗口是每周三，不是周五。
```

## 记忆边界

Xpert Tag 的默认记忆策略应更保守：

- 私有群记忆只对该群可见。
- 公开群记忆默认也只写入该群，不自动跨群共享。
- 组织管理员可以显式启用“公开群记忆共享”。
- 群成员可以添加普通记忆。
- 群管理员可以删除、锁定或修正群记忆。
- 所有记忆变更都要进入审计。

以上均为 `未实现（规划）`。当前可复用 [长期记忆](../agent/long-term-memory) 和 [文件记忆](../agent/file-memory-dreaming) 的基础能力，但它们还不是群级 Tag memory store。

## 例行任务 Routines

Routine 是由群创建和管理的长期任务。它使用该群绑定的数字专家、知识库、工具和权限运行。

| Routine 类型 | 示例 | 状态 |
| --- | --- | --- |
| 定时任务 | 每个工作日 9 点总结本群未关闭问题。 | 部分实现 |
| 群消息 watch | 监听“紧急”“故障”“客户投诉”，出现时自动总结。 | 未实现（规划） |
| 外部事件订阅 | PR、CI、工单、审批状态变化后回群。 | 未实现（规划） |
| 跟踪任务 | 持续追踪一个合同、审批、PR 或问题直到关闭。 | 未实现（规划） |
| 自然语言创建 | 用户在群里说一句话即可创建 routine。 | 未实现（规划） |

当前 Xpert 可通过 [Schedule Trigger](../plugin/trigger/schedule-trigger) 和定时任务工具实现固定周期任务，但还没有“从群聊自然语言创建、列出、修改、暂停、恢复、删除 routine”的统一产品体验。

## Routine 管理命令

目标命令：

```text
@Xpert 每个工作日 9 点，总结这个群昨天未关闭的问题，并列出负责人。
@Xpert 每天下午 5 点，汇总今天项目进展、阻塞和明天计划。
@Xpert 监听这个群里的“紧急”“故障”“客户投诉”，出现时自动总结并提醒负责人。
@Xpert 列出这个群的例行任务。
@Xpert 暂停周五周报。
@Xpert 恢复每日站会摘要。
```

管理能力状态：

| 能力 | 状态 |
| --- | --- |
| 按 Cron 触发数字专家 | 已实现基础能力 |
| 在群里自然语言创建定时任务 | 未实现（规划） |
| 列出本群 routines | 未实现（规划） |
| 修改执行时间和输出格式 | 未实现（规划） |
| 暂停、恢复、删除 routine | 未实现（规划） |
| 查看最近执行记录 | 未实现（规划） |
| 失败重试和异常提醒 | 部分实现 |

## PR 和工单跟踪

Xpert Tag 的工程类 routine 目标包括：

- 订阅某个 PR，当 CI 结束、评审到达或合并时回群。
- 从群里的 bug 报告触发代码分析，必要时创建 draft PR。
- 追踪工单状态，超时后提醒负责人。
- 把群讨论沉淀为 Issue、需求或审批草稿。

当前 [Coding Expert](../agent/toolset/coding-expert) 已具备代码平台连接、Issue/PR 和代码任务基础能力，因此 GitHub/GitLab/Gitee/云效方向为 **部分实现**。但“从群聊直接创建 PR follow routine 并持续回群”的完整 Xpert Tag 流程为 `未实现（规划）`。

## 与技能的关系

群记忆保存短小、稳定、群内共享的事实。技能保存可复用的流程、模板和任务说明。建议分工如下：

| 内容 | 放在哪里 |
| --- | --- |
| “本群日报用表格输出” | 群记忆 |
| “客户方案输出不要出现内部代号” | 群记忆 |
| “售前方案生成完整 SOP” | 技能 |
| “代码审查规范和 PR 模板” | 技能或代码仓库规则 |
| “审批流和工单字段映射” | 工作流或插件配置 |

当某条群记忆变长、变复杂或需要跨群复用时，应沉淀为技能或工作流模板。
