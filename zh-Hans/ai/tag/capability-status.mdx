本页汇总 Xpert Tag 的当前基础能力、部分实现能力和后续规划能力。状态用于产品沟通和研发排期，不代表所有能力在所有 IM 平台上体验完全一致。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 已实现基础能力 | 现有 Xpert 或插件已经具备基础能力，可通过配置组合使用。 |
| 部分实现 | 某些平台、插件或工具已支持，但还缺统一 Tag 产品体验。 |
| 未实现（规划） | Xpert Tag 产品目标，后续需要新增产品、后端、前端或治理能力。 |

## 推荐下一步研发顺序

1. **Tag tab 和文档上线**：完成当前文档与导航，明确产品边界。
2. **Tag 管理模型**：定义平台、群、数字专家、触发策略和 session 的统一 schema。
3. **能力状态页**：在后台展示现有 IM 集成、触发器绑定、连接状态和最近错误。
4. **Access Bundle v1**：先支持知识库、工具集、模型、写操作开关和预算。
5. **统一进度事件**：定义 progress event，让 [飞书](../plugin/integration/lark-integration)、[钉钉](../plugin/integration/dingtalk-integration)、[企业微信](../plugin/integration/wecom-integration) 分别渲染。
6. **群记忆 v1**：支持记住、查看、修正、删除和审计。
7. **Routine v1**：从 Schedule Trigger 开始，支持自然语言创建和群内管理。
8. **审计与用量**：补齐 Tag session 级审计、成本和失败分析。
