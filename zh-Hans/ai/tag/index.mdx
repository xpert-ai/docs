Xpert Tag 是把 Xpert 数字专家接入企业 IM 群聊和单聊的频道级智能体能力。团队成员可以在 [飞书](../plugin/integration/lark-integration)、[钉钉](../plugin/integration/dingtalk-integration)、[企业微信](../plugin/integration/wecom-integration) 会话中通过 @ 机器人把任务交给数字专家，数字专家基于当前会话上下文、知识库、工具集、工作流和业务系统完成工作，并把过程和结果回到原会话。

<Tip>
当前 Xpert 已具备多 IM 接入、触发器、会话续接、消息汇总、卡片/通知和部分上下文读取等基础能力。本文档中的 `未实现（规划）` 能力表示 Xpert Tag 产品化目标，不代表当前版本已经可用。
</Tip>

## 产品定位

Xpert Tag 不是简单的 IM webhook 机器人，也不是要把 [飞书](../plugin/integration/lark-integration)、[钉钉](../plugin/integration/dingtalk-integration)、[企业微信](../plugin/integration/wecom-integration) 插件重写成一个统一插件。它是在已有通信插件和 Xpert 平台能力之上，形成一套可治理的群组智能体产品体验：

- **群组即工作空间**：项目群、支持群、告警群、销售群和需求群都可以拥有自己的数字专家。
- **权限跟随群组**：群里能用什么知识库、工具、插件和业务系统，由管理员配置，而不是由提问者个人权限临时决定。
- **过程对团队可见**：任务进度、关键工具调用、结果和可追溯记录都回到原群聊或线程。
- **结果不限于聊天**：输出可以是摘要、文档、工单、图表、指标分析、代码变更建议或 PR 链接。
- **长期沉淀为团队能力**：群规则、输出格式、例行任务和高频流程可以沉淀为记忆、routine 和技能。

## 与现有 IM 插件的关系

| 平台 | 当前基础能力 | Xpert Tag 产品化方向 |
| --- | --- | --- |
| [飞书 / Lark](../plugin/integration/lark-integration) | 长连接或 Webhook、群聊 @、单聊、会话绑定、群消息范围、消息汇总、卡片/更新、消息历史与资源读取、文档源能力。 | 在群/频道维度配置数字专家、知识库、工具包、记忆、routine 和审计。 |
| [钉钉](../plugin/integration/dingtalk-integration) | Stream 或 HTTP、群聊 @、单聊、会话绑定、消息汇总、文本/Markdown/交互卡片、卡片回调、更新/撤回。 | 用统一的 Tag session、进度卡片和群级权限模型承载长任务。 |
| [企业微信](../plugin/integration/wecom-integration) | 短连接或长连接、单聊/群聊、会话绑定、消息汇总、模板卡片、流式/思考提示、图片输入、`/new` 重置。 | 按平台能力差异提供 Tag 体验，并对不支持的群能力做降级说明。 |

## 复用的 Xpert 能力

| Xpert 能力 | 在 Xpert Tag 中的作用 | 状态 |
| --- | --- | --- |
| 数字专家 | 群内可 @ 的任务执行主体。 | 已实现基础能力 |
| 工作流 | 固化业务流程、分流、审批、信息抽取和工具调用。 | 已实现基础能力 |
| 知识库 | 支撑群内问答、政策查询、项目资料检索和文档审查。 | 已实现基础能力 |
| 工具集 | 连接外部 API、数据分析、通知、文件、代码、浏览器和虚拟环境。 | 已实现基础能力 |
| 技能 | 复用团队流程、输出模板和任务规则。 | 已实现基础能力 |
| Schedule Trigger | 定时触发日报、巡检、同步和报告任务。 | 已实现基础能力 |
| Coding Expert | 连接 GitHub、GitLab、Gitee、云效，处理 Issue、PR 和代码任务。 | 部分实现 |
| 群级 Access Bundle | 按群组合知识库、工具、凭证、模型、预算和写权限。 | 未实现（规划） |
| 群级记忆 | 保存群规则、项目事实、决策和输出格式。 | 未实现（规划） |
| Tag 管理后台 | 独立配置群、专家、权限、记忆、routine、审计和用量。 | 未实现（规划） |

## 典型体验

用户在项目群中发送：

```text
@Xpert 总结这个需求讨论，给出 PRD 草稿，并列出还缺哪些确认项。
```

Xpert Tag 的目标体验是：

1. 创建一个与该群/线程绑定的 Tag session。
2. 读取当前消息、引用链、已授权群上下文、附件、知识库和工具配置。
3. 先回复“已开始处理”，并用进度列表或卡片展示任务步骤。
4. 调用知识库、数据、工单、文档或代码工具。
5. 在群内返回 PRD 草稿、来源摘要、待确认项和下一步按钮。
6. 把本次任务、工具调用、结果和费用记录进审计与用量视图。

其中第 1、2、4 步已可由现有 IM 触发器和数字专家能力组合实现；统一 Tag session、群级权限、live checklist、群记忆、routine 和用量审计属于后续产品化目标。
