日常工作中，你可能需要临时解释一个概念、起草一条培训通知，或者把一段文字改得更简洁。通过 Xpert 助理，可以直接在飞书、钉钉或企业微信中向机器人发送需求，由 ClawXpert 处理并在原会话中返回结果。

本教程以“为销售团队起草产品培训通知”为例，带你完成助理接入，并通过连续对话补充地点、调整语气，得到一条可直接使用的通知。

## 完成本教程后，你可以

- 在聊天软件中向助理提问并收到回答。
- 根据时间、对象和内容要求生成通知草稿。
- 在同一会话中补充条件，继续修改上一版内容。
- 确认助理已正常接入，并排查常见的无回复问题。

本教程使用文字消息和模型的问答、写作能力。通知所需信息由你在对话中提供，无需提前准备知识库。

## 开始前的准备

| 准备事项 | 如何确认 |
| --- | --- |
| 可用的 Xpert 账号 | 能登录 Xpert，并进入目标组织 |
| 可运行的 ClawXpert | 已绑定一个配置好模型、完成发布的智能体，网页对话可以正常回答 |
| 对应平台插件 | 助理设置中可以看到飞书、钉钉或企业微信触发器 |
| 平台账号与权限 | 能登录对应客户端，并有权创建、管理或授权本次使用的机器人 |
| 正常的服务连接 | Xpert 服务保持运行，能够连接消息平台并调用模型 |

首次配置由有相应权限的人员完成。如果管理员已经连接好机器人，可以直接从“发送第一个问题”开始体验。

## 第一步：准备 ClawXpert

打开 Xpert 的 **ClawXpert 概览与配置页**，确认当前助理绑定的是本次需要使用的智能体。

1. 尚未绑定时，选择一个已发布的智能体并保存。
2. 如果没有可选智能体，使用 **新建 ClawXpert** 创建，或先完成已有智能体的模型配置与发布。
3. 点击 **去对话**，发送“你好，请用一句话介绍你能帮助我做什么”。
4. 确认网页中能够正常收到回复，再进行平台接入。

如果希望助理保持统一的写作习惯，可以在目标智能体的提示词中加入以下要求，并保存、发布：

```text
你是一名办公助理，帮助用户回答日常问题、起草通知和修改文字。
默认使用简体中文，表达简洁、明确。
起草通知时保留用户给出的时间、地点、参加对象和准备事项。
没有提供的关键信息不要自行编造，可以询问用户或标为待补充。
用户继续修改时，保留此前已经确认的要求。
```

> 助理设置中的扫码连接会绑定到当前 ClawXpert 对应的智能体。开始扫码前，请先核对目标。

## 第二步：连接你使用的聊天平台

展开 Xpert 左侧导航，点击 **助理**旁的设置按钮，进入 **助理设置**。在“可用触发器”中选择你的平台，按下面对应的步骤完成连接。

### 飞书

1. 在 **飞书触发器**卡片中点击 **连接**。
2. 使用国内飞书客户端扫描二维码。
3. 在飞书授权页面选择已有个人应用，或按提示新建应用，完成授权确认。
4. 返回 Xpert，等待显示 **“机器人已连接，可以发送消息。”**
5. 在飞书中打开刚刚授权的机器人会话。

当前飞书扫码入口使用国内飞书的个人应用授权流程。已有普通自建应用如果不在可选列表中，可以使用下文的“已有机器人如何接入”路线。

### 钉钉

1. 在 **钉钉触发器**卡片中点击 **连接**。
2. 使用钉钉客户端扫描二维码。
3. 按钉钉页面完成机器人相关设置和授权确认。创建或选择机器人的选项以平台页面为准。
4. 返回 Xpert，等待显示 **“机器人已连接，可以发送消息。”**
5. 在钉钉中打开该机器人的会话。

手机端显示“已扫描”时，可能仍有待确认步骤。请完成平台上的授权，并以 Xpert 的连接状态为准。

### 企业微信

1. 在 **企业微信触发器**卡片中点击 **连接**。
2. 使用企业微信客户端扫描二维码。
3. 按企业微信页面完成智能机器人的设置与授权确认。
4. 返回 Xpert，等待显示 **“机器人已连接，可以发送消息。”**
5. 打开该智能机器人支持的会话入口。

这里接入的是企业微信智能机器人的长连接模式，日常使用范围以该机器人支持的会话和平台授权范围为准。

> 从助理设置直接扫码并连接成功后，本次平台接入立即生效，无需再发布一次触发器。前提是 ClawXpert 已有可运行的发布版本。只扫描二维码、尚未完成授权确认时，接入还没有完成。

### 已有机器人如何接入

如果管理员已经准备好机器人及凭据，可以先创建系统集成，再绑定到助理：

| 平台 | 系统集成提供商 | 需要准备的凭据 |
| --- | --- | --- |
| 飞书 | 飞书，连接方式选择“长连接” | App ID、App Secret |
| 钉钉 | 钉钉-Stream模式 | Client ID（AppKey）、Client Secret（AppSecret） |
| 企业微信 | 企业微信-长连接 | Bot ID、Secret |

1. 在 **助理设置 → 新建系统集成**中选择对应提供商，填写凭据，完成测试并保存。平台侧还需具备消息接收、回复能力，并对测试人员开放。
2. 回到 **ClawXpert 概览与配置页 → 触发器配置草稿**。
3. 新增或编辑对应平台触发器，选择已创建的系统集成，打开 **启用**。
4. 点击 **保存草稿**，再点击 **发布**。
5. 返回助理设置刷新状态，然后到平台测试消息收发。

这条路线需要发布触发器配置。仅保存系统集成，还没有完成助理绑定。通过“新建系统集成”页面扫码创建集成后，也需要继续完成绑定和发布。

## 第三步：发送第一个问题

在刚连接的机器人会话中发送：

```text
写一条内部培训通知，通常需要包含哪些信息？请用五个要点回答。
```

助理应在当前会话中返回回答，例如培训主题、时间、地点、参加对象和准备事项。具体措辞可能不同，重点是确认问题能够送达，并收到与问题相关的回复。

如果使用的是支持机器人的群聊，请先确认机器人已经入群，并在提问时 **@ 机器人**。飞书默认仅在群内被 @ 时触发回复。

## 第四步：起草一条培训通知

继续在同一会话中发送具体要求：

```text
请帮我起草一条内部培训通知：
明天下午三点进行产品培训，参加人员是销售团队。
请提醒大家提前十分钟到场。
语气简洁，正文不超过一百字。
地点暂时没有确定，请标为待确认。
```

助理应返回一份包含已知信息的通知草稿。以下仅为内容示例：

> 【产品培训通知】
>
> 请销售团队全体成员于明天下午三点参加产品培训，并提前十分钟到场。培训地点待确认，后续另行通知。

核对草稿是否保留了培训时间、参加对象和提前到场要求，并将尚未确定的地点标为待确认。

## 第五步：补充地点，继续修改

收到草稿后，无需重新发送整段要求。在同一会话中继续输入：

```text
地点确定为二楼会议室，请更新通知，其他要求保持不变。
```

助理应保留时间、对象和到场要求，更新培训地点。接着可以继续调整表达：

```text
再改成适合发在工作群里的语气，只返回最终通知正文。
```

最终内容可以类似于：

> 各位销售同事，明天下午三点将在二楼会议室进行产品培训，请大家提前十分钟到场，谢谢配合！

确认内容后，复制到需要发布的工作群或通知渠道。

> 本教程中的结果会返回到你与机器人的当前会话。“写一条通知”不会自动把通知发送给所有参加人员。

### 连续对话的使用习惯

为了让助理准确沿用之前的要求，建议在同一个平台、同一个会话中连续完成修改。超过触发器设置的会话空闲超时时间后，下一条消息会按新会话处理，此时应重新提供需要保留的背景信息。

如果习惯把同一项需求分成多条消息发送，管理员可以在触发器中设置 **汇总时间**，让连续消息先合并再交给智能体处理。默认值为 `0`，表示不等待汇总。调整后需要保存草稿并发布；开启汇总也会增加回复前的等待时间。

## 确认已经可以使用

| 检查内容 | 操作 | 完成标志 |
| --- | --- | --- |
| 网页中的智能体 | 在 Xpert 中发送一句简单问题 | 能正常回答 |
| 平台连接 | 在助理设置中刷新状态 | 显示“机器人已连接，可以发送消息。” |
| 日常问答 | 询问培训通知应包含哪些信息 | 在平台会话中收到相关回答 |
| 通知起草 | 提供时间、对象和提前到场要求 | 草稿包含关键信息，没有编造地点 |
| 连续修改 | 补充二楼会议室，再调整语气 | 更新地点并保留此前确认的要求 |
| 群聊使用（按需） | 在允许的群中 @ 机器人提问 | 在该群收到回复 |

这里检查的是实际回复内容。仅看到连接成功、集成保存成功或机器人已经入群，都不能替代一次完整的消息测试。

## 常见问题

### 助理设置中没有对应平台入口

先确认已进入正确组织、完成 ClawXpert 绑定，再点击 **刷新**。仍没有入口时，请管理员检查是否安装并启用了对应平台插件。

### 二维码已经扫描，为什么还没有连接成功

查看手机端是否还有授权确认步骤。二维码过期时，点击 **重试**生成新的二维码。等待 Xpert 显示机器人已连接，再发送测试消息。

### 创建了系统集成，机器人却没有回复

如果是在“新建系统集成”页面完成配置，还需要选择该集成、启用平台触发器，保存草稿并发布。可以回到“已有机器人如何接入”检查是否遗漏了绑定步骤。

### 显示已连接，但发消息仍然没有回复

依次检查：

1. 发消息的机器人是否与本次授权或绑定的机器人一致。
2. 目标 ClawXpert 在 Xpert 网页中是否能正常回答。
3. 测试账号是否在平台允许使用机器人的范围内。
4. 群聊中是否已添加机器人，并按要求 @ 它。
5. 采用手动配置时，消息权限、触发器启用和发布步骤是否完成。

### 补充地点后，助理没有沿用前面的通知

确认仍在同一个会话中，且没有超过设置的会话空闲超时时间。可以重新发送当前通知正文，并明确说明“在这份通知中将地点改为二楼会议室，其他内容保持不变”。

### 关闭 Xpert 网页后，还能使用平台助理吗

连接成功后，消息由 Xpert 服务处理，日常使用不需要一直打开网页或二维码窗口。Xpert 服务、平台连接和模型服务需要保持可用。
