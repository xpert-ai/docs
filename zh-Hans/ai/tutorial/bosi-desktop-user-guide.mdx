Bosi（完整名称 Xpert Bosi）是 Xpert 平台的桌面应用，定位是“你的 AI 小队长”：你定目标，Bosi 带队。使用 Xpert 账号登录后，你可以在同一个桌面窗口中查找并添加数字专家、应用和智能体模板，与助手对话，并使用对话中的文件、工具和工作台。

本教程带你完成从下载安装、首次登录到日常使用的全过程，并介绍常用设置、应用更新和常见问题。

Bosi 的完整产品介绍见 [Bosi App](/zh-Hans/ai/bosi/index)。新版个人助手初始化见[开始使用 Bosi](/zh-Hans/ai/bosi/quickstart)，公开助手形象与本机偏好的区别见[个性化、设置与更新](/zh-Hans/ai/bosi/desktop-guide/personalization-and-settings)。

## 完成本教程后，你可以

- 为自己的电脑选择并安装合适的 Bosi 安装包。
- 连接官方 Xpert 服务或组织自行部署的 Xpert 服务，并完成登录。
- 选择组织和助手，开始对话，并整理侧栏中的助手列表。
- 在设置中调整语言、外观和服务连接，查看用量与积分。
- 更新 Bosi，并排查常见的连接与登录问题。

Bosi 本身不包含 Xpert 后端，使用时需要联网连接 Xpert 服务。你能看到的专家、应用和工具，取决于所在组织的权限和配置。

## 开始前的准备

| 准备事项 | 如何确认 |
| --- | --- |
| 可用的 Xpert 账号 | 能使用邮箱和密码登录 Xpert，并加入目标组织 |
| 服务地址（自行部署时） | 已从管理员处获得 API 服务、Xpert 网页和 ChatKit 三个地址 |
| 已发布的助手 | 组织中至少有一个你可以使用的已发布助手，或者你可以从目录中添加 |
| 网络连接 | 电脑可以访问对应的 Xpert 服务 |

使用官方服务时，无需准备服务地址，Bosi 默认连接官方服务。

## 第一步：下载并安装 Bosi

从以下任一位置下载安装包：

- [Bosi 下载页](https://xpertai.cn/zh-CN/download/)
- [GitHub Releases](https://github.com/xpert-ai/xpert/releases)：桌面应用的版本以 `desktop-v` 开头，提供全部安装包、压缩包和 SHA-256 校验文件。

每个平台都提供 x64 和 ARM64 两种安装包，请按电脑的处理器选择：

| 平台 | 安装包格式 | 如何确认处理器 | 安装方式 |
| --- | --- | --- | --- |
| macOS | `.dmg` | 在苹果菜单 → 关于本机中查看芯片或处理器 | 打开 DMG，将 Bosi 拖入「应用程序」 |
| Windows | `.exe` | 在设置 → 系统 → 系统信息中查看系统类型 | 运行 EXE 安装程序 |
| Linux | `.AppImage` | 运行 `uname -m`：`x86_64` 对应 x64，`aarch64` 对应 ARM64 | 在文件属性中允许 AppImage 作为程序执行，然后打开 |

各平台安装包的签名与公证情况以对应版本的发布说明为准。未签名的安装包在安装或首次打开时，可能需要你在操作系统的安全提示中确认。

## 第二步：连接 Xpert 服务

使用官方服务时可以跳过这一步。Bosi 默认连接以下地址：

| 设置项 | 默认值 |
| --- | --- |
| API 服务地址 | `https://api.xpertai.cn/api/` |
| Xpert 网页地址 | `https://app.xpertai.cn/` |
| ChatKit 地址 | `https://app.xpertai.cn/chatkit` |

连接组织自行部署的 Xpert 服务：

1. 在登录页点击 **连接设置**。
2. 按管理员提供的信息填写 API 服务地址、Xpert 网页地址和 ChatKit 地址。API 地址可以包含 `/api`，也兼容原有的服务根地址。
3. 等待页面自动检查地址和证书，确认没有错误提示。
4. 点击 **保存设置**，再点击 **返回登录**。

填写服务地址时请注意：

- 服务地址需要使用 HTTPS；只有本机 `localhost` 地址可以使用 HTTP。地址不能包含账号或查询参数。
- 如果组织使用自签名证书或你信任的私有部署，可以开启 **允许不受信任的服务证书**。此项默认关闭，只对当前配置的 API、网页和 ChatKit 服务主机生效，开启后不再校验这些主机的证书身份。
- 修改服务地址或证书设置并保存后，Bosi 会重新加载连接，需要重新登录。
- 如果组织提供了定制安装包，服务地址可能已经预先配置好。已保存过的连接设置会优先于新安装包的默认值。

## 第三步：注册与登录

1. 还没有 Xpert 账号时，在登录页点击 **注册账号**。Bosi 会在系统浏览器中打开注册页面，完成注册和验证后，回到 Bosi 登录。
2. 使用 Xpert 邮箱和密码 **登录**。
3. 登录后，Bosi 会加载你所在的组织和可以使用的已发布助手。在侧栏切换到目标组织。
4. 在侧栏选择一个助手开始对话，或者从目录中添加专家、应用和助手。

登录凭证通过操作系统的安全存储加密保存，下次打开时会自动恢复登录；密码不会被保存。在 macOS 上，Bosi 使用钥匙串保存凭证，启动时可能弹出钥匙串授权提示。

## 第四步：添加助手并开始对话

### 发现与添加

点击侧栏的 **+** 打开 **发现与添加**，可以搜索并添加：

- **数字专家**：可访问的专家可以直接使用；需要授权的专家可以填写使用场景并提交申请，审批通过后即可使用。
- **应用**：已安装的应用可以直接使用；尚未安装的应用，先查看安装要求，选择需要的向量模型或视觉模型，再完成初始化。点击应用名称或查看详情，可以浏览应用截图。
- **插件**：查看租户或组织内已安装的插件。已安装的插件可以直接在会话的 **插件** 菜单中选择使用。
- **智能体模板**：选择你有编辑权限的工作空间，填写助手名称，完成初始化和发布。

添加成功后，侧栏会刷新，并直接打开该助手的对话。各分类的详细说明见[发现与添加](/zh-Hans/ai/agent/conversation/discover-and-add)。

### 对话

窗口右侧是对话区域，嵌入的是 Xpert 的 ChatKit。消息、附件、历史会话、工具、技能、连接器和工作台都在这里使用。可以使用哪些能力，取决于所连接 Xpert 服务的功能和你的权限。

### 群组对话

在菜单 **文件 → 新建群组** 中，或使用快捷键 `Cmd/Ctrl+Shift+G`，可以创建群组，邀请同事与数字专家在同一个群组中讨论。群组中未 @ 成员时，由默认助手回复；创建后可以继续邀请成员。

## 第五步：管理侧栏中的助手

### 右键菜单

在助手上点击右键（包括置顶卡片和收起后的头像栏），可以：

- 置顶或取消置顶。
- 移至个人分组，或新建分组。
- 标为已读或标为未读。
- 编辑资料、创建副本。
- 复制会话 ID。

这些操作的作用范围不同：

- 编辑个人资料和创建副本只影响这台电脑上的列表，不会修改服务器上的助手。副本与原助手连接同一个助手，共用会话记录。
- 置顶、个人分组和侧栏布局保存在本机，按服务、账号和组织分别记录，不会同步到其他设备。
- 阅读会话或选择 **标为已读** 会更新平台上的已读状态；**标为未读** 只是本机提醒。

### 动态与未读提醒

Bosi 大约每 15 秒刷新一次助手动态，窗口重新获得焦点时也会刷新。列表中显示每个助手最新的会话标题。在 macOS 上，Dock 图标会显示当前组织的未读消息总数；需要在系统设置中允许 Bosi 显示通知和标记。

### 调整侧栏

- 拖动侧栏分隔条，可以在 240 到 520 像素之间调整宽度。
- 向左拖过最小宽度后，侧栏会收起为头像栏。
- 双击分隔条，恢复默认宽度。

### 助手资料面板

将鼠标停在助手头像上，会打开助手资料面板，包含 **动态**、**渠道**、**自动化** 和 **关于** 等标签。也可以聚焦头像后按 `Alt+Down`，固定打开面板。

- **动态**：查看最近的会话，点击可以打开对应会话。
- **渠道**：在常用应用中与当前助手对话。已安装飞书插件时，可以使用 **扫码连接**。其他渠道是否可以连接，取决于服务端是否安装了对应的 Provider 插件。
- **自动化**：在指定时间、按计划或事件发生时，让助手自动开始工作。
- **关于**：查看助手的详细说明、发布信息，以及已发布的技能、工具和子智能体数量。

管理渠道和自动化，需要助手已经发布，并且你拥有工作空间的编辑权限。资料面板的详细说明见 [Assistant 资料卡](/zh-Hans/ai/agent/assistant-profile)，自动化的配置方法见[使用 Bosi 进行开发](/zh-Hans/ai/tutorial/develop-with-bosi)。

## 第六步：调整设置

打开设置的方式：

- 点击侧栏的用户菜单，选择 **设置**。
- 使用快捷键 `Cmd/Ctrl+,`。
- macOS 在 **Bosi** 菜单中选择 **设置**；Windows 和 Linux 在 **文件** 菜单中选择 **设置**。

设置页面包含以下内容，也可以使用顶部的搜索框查找设置项：

| 分组 | 页面 | 可以设置的内容 |
| --- | --- | --- |
| 基础设置 | 常规 | 界面语言（简体中文、繁体中文、日语、英语）和日常显示偏好 |
| 基础设置 | 外观 | 桌面的浅色/深色/跟随系统、配色、字号、字体、圆角和侧栏列表间距；聊天界面的配色、字体、圆角、密度和消息展示方式 |
| — | 用量与积分 | 当前套餐、积分余额、7 天和 30 天的积分趋势，以及扣费明细 |
| 连接与能力 | 服务连接 | API 服务、Xpert 网页和 ChatKit 地址，以及允许不受信任的服务证书 |
| 连接与能力 | 本机终端 | 管理这台电脑上的命令执行，见[使用 Bosi 进行开发](/zh-Hans/ai/tutorial/develop-with-bosi) |

修改设置时：

- 改动会立即预览。点击 **保存设置** 保存，点击 **取消更改** 恢复已保存的值。
- 点击 **返回工作区** 回到原来的助手和会话；如果有未保存的改动，Bosi 会提示你确认是否放弃。
- 本机终端的设置需要在该页面单独应用。
- 首次使用时，界面语言根据系统语言初始化。登录后，优先使用账号在平台上设置的语言。

## 第七步：更新 Bosi

已安装的正式版支持应用内更新：

1. 有新版本时，侧栏底部的账号区域会出现下载图标，鼠标悬停时显示 **更新**。
2. 点击后开始下载，并显示下载进度。
3. 下载完成后，选择 **安装并重启** 或 **稍后**。选择安装并重启时，Bosi 会退出、安装更新并重新打开，请先保存当前工作。

也可以在菜单中选择 **检查更新…** 手动检查。macOS 在 **Bosi** 菜单中，Windows 和 Linux 在 **文件** 菜单中。如果提示“此版本不支持应用内更新”，请从下载页获取新版本安装包，手动安装。

## 确认已经可以使用

| 检查内容 | 操作 | 完成标志 |
| --- | --- | --- |
| 安装 | 打开 Bosi | 显示登录页 |
| 服务连接 | 在连接设置中查看地址检查结果 | 没有证书或网络错误提示 |
| 登录 | 使用 Xpert 邮箱和密码登录 | 侧栏显示组织和助手列表 |
| 对话 | 选择一个助手，发送一句简单问题 | 对话区域正常加载并收到回复 |
| 添加助手 | 在发现与添加中添加一个专家或应用 | 侧栏出现该助手并打开对话 |

## 常见问题

### 对话区域一片空白

通常是 ChatKit 地址填写错误，或者服务端没有部署对应版本的 ChatKit。在 **设置 → 服务连接** 中核对 ChatKit 地址，请管理员确认该地址指向可信的 Xpert ChatKit 部署。

### 无法连接自行部署的 Xpert 服务

先确认远程地址使用 HTTPS。**服务连接** 页面会在输入后自动检查地址，证书问题与网络问题（无法解析域名、连接超时、拒绝连接）会分别提示。如果是你信任的自签名证书，可以开启 **允许不受信任的服务证书**，保存后重新登录。

### 修改服务地址后被退出登录

这是正常现象。修改任何服务地址或证书设置都会清除登录状态，重新登录即可。

### macOS 每次打开都要求钥匙串授权

Bosi 使用钥匙串保存登录凭证。拒绝授权后需要重新登录，连接和语言设置不受影响。

### 重新安装后仍然是登录状态

重新安装可能保留用户数据目录及其中的登录状态。需要清除时，请先 **退出登录**。

### 安装模板时提示没有可用模型

组织需要配置已授权的主语言模型，并且你有权使用该模型。请管理员在 Xpert 中设置主模型的默认模型并授权，然后刷新设置。应用初始化可能还需要向量模型或视觉模型。

### 侧栏中没有可用的助手

当前工作区还没有可以使用的已发布助手。请在 Xpert 中发布一个助手后刷新，或者从 **发现与添加** 中添加。

### Dock 图标不显示未读数

在 macOS 系统设置中允许 Bosi 显示通知和标记。
