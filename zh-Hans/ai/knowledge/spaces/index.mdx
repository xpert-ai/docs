**Spaces（协作空间）**让团队与 Assistant 在聊天之外持续维护内容。可以从空白页面开始编写方案、导入资料、上传附件，或收集已生成的成果；之后回到同一份内容继续编辑和使用。

它适合项目手册、团队说明、研究笔记、方案草稿及需要持续完善的报告。

## 可以做什么

| 能力 | 使用方式 |
| --- | --- |
| 创建和整理 | 创建页面与文件夹，上传文件，搜索列表并查看最近更新 |
| 协同编辑 | 在 Markdown 页面中编辑正文、表格、公式和资源引用，查看在线协作者 |
| 与 AI 合作 | 将文档或选区交给 Assistant，生成内容、提出修改并进行审阅 |
| 导入与收集 | 导入已授权的外部文档文本副本，收集有权读取的成果版本 |
| 检索与复用 | 启用项目知识库后，按索引状态检索已保存的内容 |

## 空间如何组织内容

协作空间基于类型为“协作空间”的项目。同项目绑定的多个 Assistant 使用同一份页面和文件，成员与角色也由项目统一管理。Assistant 的个人文件设置不会为项目内容创建个人副本。

页面正文保存为项目中的 Markdown 文件。Spaces 提供内容入口与整理，具体文件能否编辑取决于已安装的编辑器。表格文件可通过配套 Office Editor 扩展；其他格式以实际可用能力为准。

## 开始使用

先按[快速开始](./quickstart)创建页面并确认保存，再阅读[内容整理](./organizing-content)、[编辑与协作](./editing-and-collaboration)和[与 Assistant 共同写作](./assistant-writing)。

Spaces 需要部署兼容的平台、Spaces 插件和 Markdown 编辑器，并为 Assistant 启用能力、发布和绑定项目。功能入口是否可用取决于当前部署及授权。

## 访问范围

所有者和管理员可以管理项目，编辑者可以修改内容，普通成员只读；已归档项目只读。能够使用 Assistant 不代表已经加入它连接的所有项目。成员管理见[项目成员与权限](../../projects/setup/members-and-permissions)。

正文检索需要另外启用项目知识库。外部文档导入生成本地副本，当前不自动同步原文更新。详见[检索与复用](./search-and-reuse)和[文档导入](./document-import)。
