在空间视图中按内容类型、目录或最近更新时间找到资料。最近更新表示内容变更时间，不是个人最近访问记录。

| 入口 | 内容 |
| --- | --- |
| 全部内容 | 页面、项目文件与已收集成果 |
| 页面 | 可交给 Markdown 编辑器打开的页面 |
| 文件与成果 | 上传文件和收集的成果；编辑方式取决于格式与编辑器 |
| 文件夹 | 项目文件的目录结构 |
| 回收站 | 已移入回收站、可按权限恢复的内容 |

## 创建与移动

新建页面可以从空白或内置模板开始。上传文件保存到当前项目目录，随后可引用、下载或使用匹配的编辑器打开。重命名和移动保留资源身份，已有引用仍可解析；目标路径冲突时，操作会被拒绝。

**文件夹与子页面表达不同关系。** 文件夹决定实际文件位置，子页面表示页面之间的父子层级。重命名或移动父页面不会自动移动子页面；父页面移入回收站也不会级联删除子页面。移动文件夹则会移动其中的实际文件。

## 收集工作成果

在 **添加素材 → 成果** 中选择已发布版本，并选择收集方式：

| 方式 | 后续行为 |
| --- | --- |
| 添加引用 | 固定一个成果版本；查看时同时检查项目权限和来源成果权限。添加引用不会向项目成员自动开放私有来源 |
| 复制到项目 | 仅在成果类型允许复制时提供；确认后创建按项目权限共享的副本，后续来源更新或撤权不会改变副本 |

点击引用名称打开只读查看页。“成果版本与分享”用于选择固定版本和管理允许的分享方式；切换引用版本不会自动修改已有分享链接的版本。公开分享需要确认，并受成果类型与来源权限限制。详见 [Artifacts](../../agent/artifacts/index)。

## 删除、恢复与导出

在权限允许时，可将内容移入回收站并恢复。被回收的资源无法继续作为有效引用打开，恢复后可以重新解析。将成果引用移入回收站只处理该引用，不删除来源成果或撤销已有分享链接。

Markdown 导出的正文可能包含需要 Xpert 授权才能解析的资源链接；当前不提供包含全部附件和页面层级的离线包。下载文件后，应打开检查正文及所需附件是否完整。
