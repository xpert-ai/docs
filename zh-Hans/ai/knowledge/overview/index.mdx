Xpert 的知识能力覆盖内容创作、团队协作与检索复用。你可以在协作空间中与成员和 Assistant 共同维护资料，也可以将已有企业文档接入知识库，让回答和分析有据可查。

## 选择适合的入口

| 你要完成的工作 | 从哪里开始 |
| --- | --- |
| 导入制度、手册和业务资料，供 Agent 检索与引用 | [知识库](../../knowledge-base/index) |
| 与团队和 Assistant 一起写页面、整理文件、维护成果 | [协作空间 Spaces](../spaces/index) |
| 在已有知识库中浏览文档、指定资料提问并追溯来源 | [知识库 Workbench](../../knowledge-base/knowledge-workbench) |

## 从内容到知识

例如，团队在 Spaces 中共同编写项目操作手册，保留页面、附件和修改记录。需要根据正文查找资料时，由项目管理员启用项目内置知识库，等待索引就绪，再让 Assistant 检索并引用内容。

知识库也可以独立接入外部资料，无需先创建协作空间。Spaces 可以先用于写作和协作；保存页面与完成知识索引是两个状态，保存成功后，新内容可能尚未进入检索结果。详见[内容检索与知识复用](../spaces/search-and-reuse)。

## 内容、项目与权限

Spaces 使用项目管理成员、角色、文件与 Assistant 连接。知识库和外部文档源继续检查各自的访问范围。将资料放入共同的“知识”栏目，不会自动共享资源或扩大权限。

需要安排工作、跟踪执行和验收交付时，阅读[项目与任务](../../projects/index)。内容平台 API 和编辑器扩展见[内容与编辑器运行时](../../plugin/plugin-sdk/content-runtime)。
