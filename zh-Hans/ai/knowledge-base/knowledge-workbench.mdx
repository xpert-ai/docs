知识库 Workbench 是面向 Xpert Assistant 的交互式知识库工作台。它把知识库目录、文档预览、文档上传、指定文档问答、检索来源定位和知识图谱浏览整合到同一个 Agent Workbench 视图中，让用户可以一边查看知识库内容，一边在右侧 ChatKit 中提问和追溯答案来源。

它适合需要“看得见、选得准、可追溯”的知识库问答场景，例如操作手册问答、法规制度查询、项目资料检索、售前资料答疑和内部培训资料助手。

<Info>
知识库 Workbench 不替代知识库节点。Agent 仍需要连接知识库节点来声明可访问的知识库范围；Workbench 在这个范围内提供浏览、预览、选中文档、结构化引用和来源打开等增强体验。
</Info>

## 功能定位

传统知识库检索通常由 Agent 自主决定何时检索，用户很难确认 Agent 搜的是哪个文件，也不容易从回答回到原始文档。知识库 Workbench 解决的是交互层和可追溯层的问题：

- **浏览知识库目录**：在 Workbench 中查看当前 Assistant 已连接的知识库、文件夹和文档列表。
- **预览文档内容**：点击文档后查看原文件信息、解析状态和 Chunk 内容，默认以 Markdown 形式预览，也可以切换为原始文本。
- **指定文档提问**：选中文档后，Workbench 会把所选文档写入对话上下文；用户直接在 ChatKit 中提问时，Agent 可以优先针对这些文档检索。
- **追溯答案来源**：Agent 检索返回的引用信息包含 `documentId`、`chunkId`、文件名和原文件地址，Workbench 可以自动高亮对应来源，并打开原文件。
- **实时上传和处理**：在 Workbench 中上传文档后，可立即触发处理，处理完成后用于后续问答。
- **知识图谱浏览**：如果知识库启用了知识图谱能力，Workbench 会显示图谱视图，用于查看实体、关系和相关片段。

## 启用条件

使用知识库 Workbench 前，需要满足以下条件：

1. Assistant 已连接至少一个知识库节点。
2. Assistant 启用了 Knowledgebase Workbench 中间件能力。
3. 知识库中的文档已完成解析和向量化，才能被稳定检索。
4. 如果需要图谱视图，知识库需要启用知识图谱索引。

启用后，Workbench 会默认展示当前 Assistant 已连接的知识库。多个知识库时，可以在顶部切换。

## 界面组成

知识库 Workbench 通常由以下区域组成：

| 区域 | 作用 |
| --- | --- |
| 知识库选择器 | 切换当前 Assistant 已连接的知识库，查看文档数量和 Chunk 数量。 |
| 知识库头部 | 展示知识库 Logo、名称、当前位置和管理入口。点击设置按钮可跳转到知识库文档管理页面。 |
| 文档列表 | 展示文件夹和文档，支持搜索、排序、新建文件夹和上传文件。 |
| 文档预览 | 查看文档解析后的 Chunk 内容，支持 Markdown 和原始文本两种模式。 |
| 图谱视图 | 在支持知识图谱的知识库中查看实体、关系和焦点实体。 |
| ChatKit 对话 | 用户在右侧直接提问，Agent 根据当前知识库和选中文档上下文进行检索。 |

## 典型使用流程

### 1. 浏览知识库内容

打开 Assistant 的 Workbench 后，进入“知识库”视图。系统会列出当前 Assistant 已连接的知识库，默认选择其中一个知识库。

你可以在目录中进入文件夹、返回上级目录，也可以通过搜索快速定位文件。

### 2. 预览文档

点击文档后，右侧预览区会显示文档名称、类型、原文件入口和解析出的 Chunk。

默认使用 Markdown 预览，适合查看从 PDF、Word、Markdown 等文件解析出的正文内容。如果需要排查解析结果，可以切换到原始文本模式。

### 3. 选中文档并提问

在文档列表或预览区选中文档后，Workbench 会把所选文档写入 Assistant 上下文。之后你可以直接在 ChatKit 中提问，例如：

```text
根据选中的操作手册，总结设备启动前的检查步骤。
```

Agent 的知识库 Workbench 检索工具会优先使用当前选中的文档范围，减少跨文档误召回。

### 4. 从回答打开来源

当 Agent 使用 Workbench 检索工具回答问题时，检索结果会携带结构化引用信息。Workbench 可以根据引用中的文档和 Chunk 定位来源：

- 自动切换到对应知识库；
- 打开对应文档预览；
- 高亮被引用的 Chunk；
- 在有原文件地址时打开原文件。

这使用户可以从答案快速回到证据位置，验证回答是否可靠。

### 5. 上传新文档

点击上传按钮选择文件后，Workbench 会把文件上传到当前知识库，并触发文档处理。处理完成后，新文档会出现在列表中，可以继续预览、选中和提问。

如果文档仍在处理中，检索结果可能暂时不完整。建议等待解析和嵌入完成后再用于正式问答。

### 6. 浏览知识图谱

如果当前知识库支持知识图谱，Workbench 会提供“图谱”视图。你可以：

- 查看知识库中的实体和关系规模；
- 搜索实体或按实体类型过滤；
- 点击实体聚焦其相关关系；
- 在右侧查看实体详情、相邻实体和提及片段。

图谱视图适合探索知识库的主题结构、概念关系和文档中的关键对象。

## 与知识库节点的关系

知识库 Workbench 和知识库节点承担不同职责：

| 能力 | 作用 |
| --- | --- |
| 知识库节点 | 声明 Agent 可以访问哪些知识库，并提供默认知识检索能力。 |
| 知识库 Workbench | 在已授权的知识库范围内提供浏览、预览、上传、选中文档、引用定位和图谱交互。 |

因此，建议的配置方式是：

1. 给 Assistant 连接需要使用的知识库节点。
2. 启用 Knowledgebase Workbench 中间件。
3. 在 Workbench 中浏览、选择和追溯文档。
4. 在 ChatKit 中自然提问，让 Agent 按当前上下文检索。

如果只连接知识库节点，Agent 仍可进行普通知识库检索，但不会有 Workbench 视图和来源联动体验。如果只启用 Workbench 但没有连接知识库节点，Workbench 没有可访问的知识库范围，无法完成有效检索。

## 适用场景

- **操作手册助手**：先选中某个设备或系统手册，再针对该手册提问。
- **法规制度问答**：按目录查看制度文件，并从答案回到原文条款。
- **项目资料检索**：在项目文件夹中定位方案、合同、纪要等文档，进行定向问答。
- **知识库质检**：预览 Chunk 内容，检查解析质量、缺失内容和召回来源。
- **图谱探索**：查看知识库中实体之间的关系，发现主题和概念连接。

## 使用建议

- 对需要精确回答的问题，先选中文档再提问。
- 对跨文档归纳问题，可以不选中文档，让 Agent 在当前知识库范围内检索。
- 回答涉及关键事实时，优先查看 Workbench 高亮的来源 Chunk。
- 上传新文档后，等待处理完成再进行正式问答。
- 若图谱关系不完整，检查知识库是否完成图谱索引。
