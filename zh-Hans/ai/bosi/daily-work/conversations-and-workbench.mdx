Bosi 的对话区域由 ChatKit 提供。你可以在同一个窗口中说明目标、上传资料、选择能力、查看工具过程，再打开旁边的 Workbench 核对结果。

## 把要求说清楚

一项有效需求通常包含工作对象、范围、预期成果和需要确认的动作。例如：

> 根据当前项目的需求文档，整理三个方案的差异与待确认事项。先输出对比草稿，注明来源，不替我发送给客户。

需要持续协作时使用项目；临时问答可以使用允许非项目对话的助手。附件、技能、插件和连接器按当前会话上下文使用，切换项目后应重新检查选择。

工具过程可以说明助手做过哪些操作；遇到审批或补充信息请求时，在对应入口处理。文字回复“完成”与实际文件、业务记录或验收结果应相互核对。

## 对话旁边的工作台

| 视图 | 适合检查什么 |
| --- | --- |
| 应用业务视图 | 表单、目录、材料、业务状态以及应用提供的操作 |
| 项目任务 | 分工、依赖、计划时间、运行尝试和验收记录 |
| 文件与成果视图 | 已保存内容、预览、版本与下载 |
| 实时看板 | 图表、筛选条件、数据刷新以及草稿和发布状态 |
| 云电脑 | 远程桌面的当前过程，并在授权后接管操作 |

可用视图由当前 Assistant、项目和应用能力决定。部分视图按需打开，可以从添加视图菜单或应用提供的入口进入；打开视图本身不会启动业务工作。

点击资源卡片，可以进入其对应的项目、业务对象或执行记录。切换会话后，视图跟随新的上下文重新加载；保留一张历史卡片不代表仍具有访问权限。

## 通过实时语音协作

已发布助手配置了实时语音能力、且当前服务支持时，可以在对话内的助手面板中选择**通话**，允许麦克风访问后开始交流。界面提供连接状态、字幕、任务进展、静音和挂断。

语音用于讨论、澄清和交办工作，实际工具与长任务仍由助手按原有权限执行。语音模型与推理模型分别配置；开启语音不会增加工具权限。

静音或挂断不会取消已经接收的后台任务。需要取消时，应明确取消具体任务并检查实际状态。切换聊天不会将正在进行的通话转移到新会话；通话仍属于发起时的助手与会话。当前桌面语音入口用于 Assistant 对话，不能据此认为群聊也支持语音会议。

## 检查正式交付

| 看到的内容 | 表示什么 |
| --- | --- |
| 回复或输出摘要 | 对过程和结果的说明，需要结合实际证据检查 |
| 工作目录中的文件路径 | 文件的工作位置，不自动构成可下载交付 |
| 正式文件交付卡片 | 指向交付时保存的文件版本，可按权限预览和下载 |
| 业务应用的成果入口 | 由应用维护的业务内容及版本，按应用流程确认 |

打开交付卡片后，先确认文件名和内容。支持预览的格式可直接查看，不支持的格式仍可下载。预览绑定交付版本，不应把后续修改后的文件当成原来的交付结果。

持续编辑的报告、文档和看板可能有草稿与正式版本之分。共享或提交前先确认当前版本和接收范围，详见 [Artifacts](/zh-Hans/ai/agent/artifacts/index)、[实时看板](/zh-Hans/ai/live-dashboard/index)与[项目文件和交付物](/zh-Hans/ai/projects/setup/files-and-deliverables)。

更完整的对话功能介绍见 [ChatKit](/zh-Hans/ai/chatkit/index)。
