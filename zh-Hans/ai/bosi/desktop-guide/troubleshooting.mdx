---
title: "Bosi 故障排查"
description: "按连接、组织、初始化、模型、工具和交付逐层定位问题，保留已完成的工作与真实执行状态。"
---

先确认问题发生在登录与连接、个人 Bosi 初始化，还是某个具体任务中。能登录、能打开助手、能执行工具和能交付文件是不同阶段。

## 连接与组织

| 现象 | 检查与处理 |
| --- | --- |
| 对话区域空白或加载超时 | 核对 ChatKit 地址，确认页面和对应资源已部署且能访问 |
| 自行部署服务无法连接 | 核对三个服务地址及 HTTPS，按提示区分证书、域名、超时和拒绝连接 |
| 修改连接后退出登录 | 服务范围已改变，重新登录并确认组织 |
| 组织、助手或项目找不到 | 先确认当前组织和筛选条件，再检查成员关系、发布状态及使用授权 |
| macOS 钥匙串提示或不能恢复登录 | 按系统提示处理；拒绝访问后重新登录，连接偏好仍可保留 |

登录成功不代表已选择正确组织。组织范围正确后仍被拒绝时，再由管理员处理实际资源权限。

## 创建 Bosi 或初始化应用

| 现象 | 检查与处理 |
| --- | --- |
| 没有“创建你的 Bosi” | 当前组织可能已绑定可用助手；先检查已有入口 |
| 初始化提示不可访问或服务升级 | 处理原绑定访问或服务版本，避免把错误当成未创建 |
| 模型列表为空 | 检查当前组织的模型配置、授权及所选能力兼容性 |
| 插件或服务列表很短 | 目录反映当前组织实际提供的包和连接定义，不是固定推荐清单 |
| 欢迎流程失败 | 使用已有流程的恢复或重试入口，不重复初始化另一位助手 |
| 应用初始化成功但业务无法运行 | 检查 Assistant 发布、模型、插件连接和业务权限，再执行小任务验证 |

选择能力、安装资源和授权外部账号需要分别完成。连接流程应使用与 Bosi 相同的账号及组织，参见[数字专家、应用与插件](../daily-work/assistants-and-apps)。

## 工具与执行位置

| 现象 | 检查与处理 |
| --- | --- |
| 没有本机 Shell 入口 | 确认使用原生 macOS 应用，且助手已启用并发布 Desktop Shell |
| 本机命令等待中 | 检查审批卡片、执行权限和设备在线状态 |
| 本机离线或忙碌 | 保持设备及应用在线，查看现有命令；离线不会自动转到云端 |
| 命令状态未知 | 核对原执行与实际文件，再决定下一步，避免重复操作 |
| 云电脑不可用 | 检查部署是否提供相应能力、模型要求与助手配置 |
| 编程工具不能打开 | 同时检查安装状态、模型兼容性和桌面操作状态 |

具体边界见[电脑与开发任务](../daily-work/computers-and-coding)。本机工作目录不是文件隔离范围；服务端返回的命令结果也不能证明本机已执行。

## 语音与交付

语音入口不可用时，检查助手已发布的实时语音配置、模型权限和部署支持。听不到声音或无法输入时，检查麦克风权限、设备选择与静音状态。断线后可以发起新通话，但不会恢复原音频会话；挂断也不会取消已接收的后台任务。

找不到文件时，区分回复中的路径、项目工作文件与正式交付卡片。下载失败可能是版本引用缺失、访问变化或文件不可用；不要用另一版本冒充原交付。任务完成状态还需遵循相应验收规则，参见[对话、工作台与交付](../daily-work/conversations-and-workbench)。

## 设置和更新

个人分组、置顶和副本不会自动同步到其他设备。公开形象与共享助手配置则可能影响其他使用者，详见[个性化、设置与更新](./personalization-and-settings)。

桌面已更新但某项功能仍缺失时，请管理员同时核对服务端、ChatKit、插件和已发布 Assistant；不要只反复安装客户端。

## 向维护者提供的信息

说明 Bosi 版本、操作系统、使用官方还是自行部署服务、当前组织、发生时间、最后一步操作及可见错误。涉及任务时，提供有权分享的任务或执行详情链接；不需要发送密码、令牌或完整私密资料。
