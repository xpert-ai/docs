从侧栏用户菜单打开**设置**，或使用 `Cmd/Ctrl+,`。设置支持搜索，修改通常会立即预览；点击**保存设置**保留，点击**取消更改**恢复。返回工作区时会保留原助手和会话，未保存的改动会提示确认。

## 个人使用偏好

| 设置 | 可以调整什么 |
| --- | --- |
| 常规 | 界面语言与日常显示偏好 |
| 外观 | 浅色、深色或跟随系统，桌面与聊天的配色、字体、字号、圆角和密度 |
| 用量与积分 | 当前套餐、积分余额、消耗趋势和明细 |
| 服务连接 | API、Xpert 网页和 ChatKit 地址及证书策略 |
| 本机终端 | 本机命令权限、Shell、起始目录和近期执行记录 |

桌面可选择已安装的字体。助手形象颜色可影响其对话主题，群聊使用配置的聊天配色。本机终端的参数使用单独的**应用 Shell 设置**操作。

## 定制助手名称与形象

在对话中的助手面板打开定制入口，可以选择内置形象、配置角色外观、选择 Pet 或上传图片。可用形象资源来自当前部署；角色预览中的表情与活动只用于设计预览，不会改变助手的真实执行状态。

公开名称和形象属于平台 Assistant，其他使用者也会看到变化。只有具备工作空间编辑权限的用户才能保存和上传；其他用户可以查看。保存形象只更新名称和头像，不会覆盖工作流、提示词或未发布草稿。

## 哪些修改会影响其他人

| 修改 | 影响范围 |
| --- | --- |
| 置顶、个人分组、本地列表副本与个人资料 | 本机当前服务、账号和组织中的显示偏好 |
| 标为未读 | 本机提醒；标为已读会更新平台阅读状态 |
| 公开名称和助手形象 | 使用该平台 Assistant 的用户 |
| 模型、提示词和能力配置 | 保存并发布后，影响该 Assistant 的后续使用 |
| 项目成员、共享资料和应用业务数据 | 对应资源授权范围内的协作内容 |

**编辑资料**中的个人部分与助手配置不同。需要修改共享模型或能力时，先核对编辑权限及影响范围；复杂编排继续在 Xpert Studio 中完成。详见 [Assistant 资料卡](/zh-Hans/ai/agent/assistant-profile)。

## 连接自己的 Xpert 服务

按管理员提供的地址配置 API、网页和 ChatKit，远程服务使用 HTTPS。保存服务地址或证书策略的变化后，Bosi 会重建连接并要求重新登录。

**允许不受信任的服务证书**用于明确可信的私有部署，默认关闭；开启后不再验证已配置服务主机的证书身份。应先核对地址和部署证书，不用这个选项处理账号或资源权限问题。

连接状态检查会区分证书与网络问题。详细地址格式和操作见[桌面应用使用指南](/zh-Hans/ai/tutorial/bosi-desktop-user-guide)。Bosi 的登录凭证在操作系统安全存储可用时加密保存；密码不会保存，安全存储不可用时凭证只保留在内存中。

## 更新客户端

支持应用内更新的已安装正式版会在账号区域显示更新入口，也可从应用菜单选择**检查更新**。下载完成后可选择**安装并重启**或**稍后**，重启前保存当前工作。

提示当前版本不支持应用内更新时，通过官方下载页获取安装包。重新安装可能保留本机用户数据与登录状态；需要清除登录状态时使用**退出登录**。

Bosi、Xpert 服务端和托管的 ChatKit 共同组成体验。只更新桌面客户端，不会自动升级服务器、业务插件、已发布助手或 ChatKit 功能。
