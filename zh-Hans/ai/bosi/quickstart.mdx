title: "开始使用 Bosi"
description: "安装客户端、选择服务与组织，初始化个人助手，并通过第一个任务检查能力和交付。"
---

准备一个可用的 Xpert 账号和能访问的组织。组织需要提供获授权的模型；使用云电脑、插件或外部服务时，还需具备相应配置。

## 1. 安装、连接与登录

从 [Bosi 下载页](https://xpertai.cn/zh-CN/download/)选择与操作系统及处理器匹配的安装包，具体版本和安装说明以发布页面为准。完整步骤见[桌面应用使用指南](/zh-Hans/ai/tutorial/bosi-desktop-user-guide)。

Bosi 默认连接官方服务。使用组织自己的服务时，在登录页打开**连接设置**，填写管理员提供的 API、Xpert 网页和 ChatKit 地址。远程服务使用 HTTPS，本机回环地址可使用 HTTP。

使用邮箱和密码登录后，确认当前组织。没有账号时，可以从登录页打开注册入口，在浏览器中完成注册后返回 Bosi。切换组织会改变可见助手、模型、应用和项目的范围。

## 2. 创建你的 Bosi

当前账号在该组织已有可用 Bosi 时，会直接打开已有助手；首次使用时进入**创建你的 Bosi**流程。

| 阶段 | 需要确认的内容 |
| --- | --- |
| 了解 Bosi | 确认希望交给助手处理的工作 |
| 插件与服务 | 选择当前组织提供的可选能力，按需连接服务；没有可选项时可能跳过 |
| 执行能力与模型 | 选择可用云电脑或本机 Shell，并选择与能力兼容、自己有权使用的模型 |
| 创建与欢迎 | 等待助手初始化并发布，进入欢迎会话，了解已启用的能力 |

云电脑可用时会默认选中，本机 Shell 初始关闭。选择本机 Shell 不会取消逐条命令审批。向导中的电脑画面是功能预览；实际电脑需要在对话中打开。

创建流程使用当前用户的私有工作空间。中断后按界面提示重试，已有助手和创建进度会被复用。欢迎消息失败时，应恢复已有初始化流程，避免反复创建副本。

## 3. 连接需要的服务

选择插件和授权外部服务是两个步骤。出现**连接账号**或授权要求时，在打开的浏览器页面完成连接，并使用与 Bosi 相同的账号和组织。

首次向导中选择的能力可作为个人 Bosi 新会话的默认选择；已有明确选择的会话和项目会话保留自己的配置。取消默认选择不会卸载工作空间里的插件。

需要额外专家或业务应用时，从侧栏添加入口打开**发现与添加**，详见[数字专家、应用与插件](./daily-work/assistants-and-apps)。

## 4. 完成一个小任务

先用一份可以共享给当前服务的资料，提出范围清晰的需求：

> 根据我上传的会议记录，整理已确认事项、待解决问题和行动清单。保留原文依据，不明确的负责人标为待确认；先给我草稿。

检查结果后，再要求修改或生成正式文件。若希望生成可下载文档，先确认助手已启用对应文档能力，并检查实际交付卡片。处理持续工作时，在开始新会话前选择[项目](./daily-work/projects-and-groups)。

## 怎样确认已经准备好

| 检查 | 完成标志 |
| --- | --- |
| 账号与组织 | 侧栏显示正确组织和可访问的助手 |
| 模型与对话 | 能正常发送消息并收到回复 |
| 插件与连接 | 所选能力显示可用，实际的小任务能够完成 |
| 文件交付 | 可以打开已交付版本，核对内容并下载 |
| 电脑能力（按需） | 能打开已授权的云电脑，或审批并核对一次本机命令 |

遇到问题时先定位是连接、初始化、模型授权还是具体工具失败，参见[故障排查](./desktop-guide/troubleshooting)。
