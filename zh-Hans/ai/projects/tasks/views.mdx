在项目工作台打开**项目任务**，或从项目会话的 Workbench 打开同名入口。两处使用同一任务视图；早期版本可能显示为“任务与时间线”。

## 四种视图

| 视图 | 适合回答的问题 |
| --- | --- |
| 全部任务 | 当前有哪些任务，谁负责，处于什么状态？ |
| 任务树 | 一项目标拆成了哪些子任务？ |
| 甘特图 | 计划时间、真实执行时间和前置依赖怎样关联？ |
| 状态看板 | 哪些任务未开始、在执行、待验收或被阻塞？ |

四种视图共用搜索和筛选，可以按状态、负责的 Assistant 和任务结构类型缩小范围。列表和甘特图还可调整分组、排序及显示字段。窄面板中，一部分操作收进**更多操作**菜单。

任务的业务类型、父子结构和状态分别表达不同信息：业务类型图标说明工作类别，展开按钮显示层级，状态标记表示业务进展。应用可提供自己的任务类型，缺少类型展示时仍保留任务内容。

## 理解进度和状态

只有执行器或业务应用明确提供进度时，界面才显示百分比。没有可确认的百分比时，使用状态判断当前阶段；平台不会按耗时推算进度。

进度 100% 表示该来源报告的进展，不是任务已经验收。完成判断以[任务状态和验收记录](./execution-and-review)为准。

任务视图在可见时约每五秒同步一次，也可以手动刷新。同步显示状态，不会因为打开页面或刷新而重跑任务。

## 使用甘特图

甘特图区分计划日期和各次执行的实际区间；没有计划日期的任务显示为未排期。

- 选择小时、天或周粒度，观察短任务或长期安排。
- 缩放与拖动用于改变可视范围。
- **适应全部**用于查看整体，**定位到现在**用于回到当前时间。
- 结合依赖连线检查任务顺序。

这些操作仅改变显示，不会修改排期或启动任务。要改日期，请打开任务详情。

## 打开任务详情或某次执行

点击**任务名称**，打开居中详情窗口：

| 页签 | 查看内容 |
| --- | --- |
| 概览 | 目标、负责人、完成要求、层级、依赖与排期 |
| 执行记录 | 每次实施或审查、运行状态、结果投递情况以及验收和返工记录 |
| 产物 | 按执行分组的已提交文件、交付状态和诊断信息 |

任务行或看板卡片上的**执行圆点**对应一次特定尝试。点击圆点打开那次执行；同一个任务多次返工时，可以分别检查每次过程，避免把旧结果当成最新结果。

Coding 执行打开独立查看器，展示已记录的回复、工具、命令输出和文件变更。可以搜索已加载的内容、暂停跟随并复制记录；它是过程查看器，不是可输入命令的终端。其他执行使用各自可用的导航入口。

## 应用任务与历史记录

业务应用的任务也可以出现在统一视图中，但其状态规则和可编辑项仍由所属应用管理。源业务发生变化后，任务视图可能短暂保留之前的状态；刷新仍未同步时，应检查应用的业务结果和提示。

部分历史执行没有可跳转的目标，或关联资源已删除、权限已变化。此时可以阅读保留的任务信息，但不能用一条历史卡片代替实际结果。遇到异常时参见[故障排查](../help/troubleshooting)。
