项目类型说明这项工作由谁管理、应从哪里创建和打开。一个项目可以连接多位 Assistant；类型不会因为换了一位 Assistant 就改变。

## 通用项目与业务应用项目

| 类型 | 适用情况 | 创建和管理方式 |
| --- | --- | --- |
| 通用项目 | 研究、分析、内容制作等持续工作 | 通过平台项目入口创建，管理共同资料、成员和任务 |
| 应用项目 | 由已安装业务应用提供的工作空间 | 按应用提供的项目类型和创建入口操作 |
| 关联业务对象的项目 | 项目对应一个案例、业务单据等对象 | 由业务应用维护名称和生命周期，从对应业务流程进入 |
| 未分类的历史项目 | 早期创建、没有明确类型的项目 | 可在未分类筛选中查找，不根据名称推断所属应用 |

关联业务对象的项目不能通过通用项目操作任意改名、复制、归档或删除。请回到所属应用处理业务对象；应用不可用时，也不会自动将其转换成通用项目。

## 查找已有项目

在项目列表中使用名称搜索、状态筛选以及应用和类型筛选。点击项目的类型前缀，可以查看同类项目；更多结果通过分页加载。

在会话的项目选择器中，可搜索当前 Assistant 可使用的项目，按类型分组浏览或切换到最近更新视图。**最近更新**表示项目内容的更新时间，不是你最后打开它的时间。

如果找不到项目，先检查当前组织、应用类型和搜索条件，再确认自己是该项目成员且当前 Assistant 已关联。选择器只展示当前上下文中可用的项目。

## 开始对话前确认项目

| 选择 | 后续行为 |
| --- | --- |
| 已有项目 | 本次新会话使用所选项目的上下文 |
| 发送时创建 | 支持该方式的 Assistant 在首次发送时创建并绑定项目 |
| 不使用项目 | 在允许个人会话的 Assistant 中，以非项目会话继续 |

需要项目的 Assistant 可能不提供“不使用项目”。应用可能还有额外创建步骤，应完成界面要求；创建失败时先查看原因，不要反复创建同名项目。

已有会话保留其项目归属。重新打开会话、重试或继续回复会复用已保存的项目，不会为每一轮消息创建新项目。切换到另一个项目开始的是另一个工作上下文，不会把旧会话搬过去。

切换项目时应重新检查附件和文件引用。选择器可能保留纯文本草稿，但会清理上一项目的文件选择，避免把资料带入错误的项目。

## 群聊与个人会话的区别

个人会话由使用者选择项目；群聊由群主关联项目，并明确选择参与的 Assistant。群项目确定后，这个入口不能再切换到另一个项目。准备工作应尽量在正式协作前完成，详见[群聊项目协作](../tasks/group-collaboration)。

如果你是在集成自己的对话界面，开发配置参见 [ChatKit 项目选择器](/zh-Hans/ai/chatkit/chatkit-projects)。
