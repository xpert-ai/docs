在项目的**配置**页准备协作资源。先确定谁参与、使用哪些资料和工具，再开始派发任务。

## 添加参与的 Assistant

项目所有者或管理员通过**管理专家**选择当前可用的 Assistant。配置页会展示已关联的专家，可以从其中一位开始项目会话。

项目可以同时关联多位 Assistant。它们保留各自的模型、工具和授权配置；加入项目并不代表每位 Assistant 都能执行相同工作。项目关联也不同于群聊成员选择：要派发给群成员，还需要把该成员明确选入群项目。

需要创建、读取、派发或验收任务的 Assistant，应开启**项目管理**能力。创建 Assistant 时可在能力选项中启用，使用支持工具调用的模型；已有 Assistant 可在支持的能力设置中调整。项目通用 Assistant 默认具备任务管理能力。

<Note>
开启项目管理会为 Assistant 配置任务工具和指令，不会授予用户项目权限、创建项目或安装 Computer 等执行环境。高级工作流也可在 Studio 中连接 Project Tasks 插件节点。
</Note>

## 保存项目指令

在**项目指令**中保存长期适用的要求，例如术语表、信息来源、输出语言和交付规范。保存后，它们作为项目共同上下文供后续工作使用。

```text
本项目评估企业协作产品。
所有价格注明币种、计费周期、来源链接和查询日期。
结论分为已确认、推断和待确认，缺失数据不得补写为事实。
最终报告包含对比表、推荐理由和检查记录。
```

单次工作范围放在任务描述和完成要求中；持续适用的规范放在项目指令中。修改规则后，应重新检查尚未验收任务的要求，避免按照旧标准确认新结果。

## 安装和管理项目技能

在**项目技能**中选择**添加项目技能**：

1. 从技能仓库选择可用技能，或上传技能 ZIP 包。
2. 安装后检查技能名称、说明、版本及来源。
3. 在管理窗口启用、停用或卸载技能。

技能适合保存可复用的分析方法、检查步骤和文档模板。安装需要项目编辑权限；技能需要的工具和外部服务仍须由相应 Assistant 与环境提供。操作方法参见[技能概览](/zh-Hans/ai/agent/skill/index)。

## 配置连接器

进入**管理项目连接器**，选择当前部署支持的服务，建立连接并完成授权。当前项目配置界面的新增连接采用**团队授权**，由项目所有者或管理员维护。

团队授权使项目中的已授权操作能够使用统一配置的业务账号。连接器本身允许访问的对象和操作仍受外部服务权限控制；仅在项目中看见一个连接器，不代表所有操作都可执行。

个人账号连接与团队连接具有不同的授权范围。若现有任务或部署提供个人连接，只能由对应用户完成授权；不要将个人授权当作项目成员共享凭据。

连接器断开或授权失效时，先重新授权，再继续依赖该连接的工作。定时任务还需要明确选择可用连接器，详见[项目定时任务](../automation/scheduled-tasks)。

## 开始工作前核对

确认当前 Assistant 已加入项目、具备完成工作所需的工具，项目指令已保存，输入文件可读取，需要的连接器已连接。工具和知识库能力由 Assistant 及应用配置提供，不应把项目理解为一个自动拥有所有工具的容器。
