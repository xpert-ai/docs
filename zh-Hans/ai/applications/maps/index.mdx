**Maps** 把地点搜索和路线查询放进 Xpert 对话。你可以让地图助手寻找地点，再在右侧工作台通过地图标记、结果卡片和路线面板继续探索，适合会面地点比较、周边设施查询和出行路线准备。

## 核心能力

| 能力 | 可以完成的工作 |
| --- | --- |
| 地点搜索 | 按关键词和城市搜索，也可围绕指定位置或当前地图区域寻找附近地点 |
| 地图探索 | 拖动、缩放、显示全部地点，点击标记或结果卡片联动选择 |
| 地点详情 | 查看地图服务返回的名称、地址、类别及可用的电话信息，复制地址 |
| 路线规划 | 从搜索结果选择起终点，切换步行或驾车，查看路径、距离和预计时长 |
| 对话引用 | 将选中地点加入当前输入框，补充问题后继续与助手讨论 |

## 开始使用

由管理员完成[应用启用与授权](/zh-Hans/ai/applications/app-guide/discovery-and-setup)，配置主模型，并在应用工作空间连接、授权高德地图或腾讯地图。默认使用高德；切换服务由助手配置决定。真实地图需要对应服务的 Web Service Key，以及可用的地点、静态地图和路线服务额度。

1. **说明搜索范围。** 打开地图助手，提供城市、地点或明确的区域，再说明要找的内容。
2. **查看搜索结果。** 在地图上选择标记，或从结果卡片进入详情；需要时拖动地图并使用**搜索这片区域**。
3. **查看地点。** 核对地址和地图服务返回的详情，比较候选地点。
4. **规划路线。** 点击**规划路线**，从结果中选择两个不同地点作为起终点，选择步行或驾车。
5. **继续讨论。** 点击**引用到对话**，地点会加入输入草稿，由你补充问题并发送。

例如：

> 在杭州西湖附近找几家咖啡馆并显示在地图上，我选好两个地点后，再帮我查询它们之间的步行路线。

搜索也可以直接在地图工作台完成。助手不会自动推断你的位置，城市或位置不明确时需要补充范围。

## 真实地图与模拟演示

| 模式 | 用途 |
| --- | --- |
| 真实地图 | 使用当前助手获授权的高德或腾讯地图连接器，查询与路线坐标发送到对应服务 |
| 模拟演示 | 使用明确标注的虚构地点、底图、距离和时长，用于体验交互，无需地图凭据 |

正式应用入口使用真实地图。模拟演示通过独立的**地图助手 · 模拟演示**模板开启，结果不能用于实际导航；真实请求失败时不会自动切换为模拟结果。

## 使用边界

- 地图提供搜索与路线查看，不追踪实时位置，也不保存收藏或持久化行程。
- 地点详情以服务实际返回的信息为准；当前路线支持步行与驾车。
- 拖动或缩放结束后会刷新底图，服务响应可能带来短暂等待。搜索失败时，可检查范围、连接器授权和服务额度后重试。

连接器创建后还需授权给当前助手；密钥由服务端管理。通用配置说明见[发现与启用应用](/zh-Hans/ai/applications/app-guide/discovery-and-setup)。
