**Bid Studio** 是 Xpert 面向投标团队的标书应用，适用于工程、货物和服务类投标，支持技术标、商务标及联合编制。向**标书助理**说明目标后，专业助手分工处理资料、目录、正文和商务材料，你可以在 Workbench View 中查看进度、修改内容并导出文件。

## 核心能力

| 能力 | 可以完成的工作 |
| --- | --- |
| 招标解读 | 从招标文件和清单中提取项目概况、评分要求与商务义务，保留原文定位，便于核对 |
| 目录规划 | 围绕响应要求安排章节职责、编写思路和篇幅，确认目录后再推进正文 |
| 技术标编写 | 按一级章组织任务，结合资料生成正文与配图；已完成章节可继续补充、修改，并保留历史 |
| 商务标编制 | 组织应交材料、填写可支持的原表单、关联企业证明，通过独立审校检查内容与跨卷一致性 |
| 复核与交付 | 对照响应矩阵检查覆盖与缺项，导出已有正文或技术、商务分卷包，核对实际附件及递交准备 |

## 开始使用

首次使用前，由管理员完成[应用启用与授权](/zh-Hans/ai/applications/app-guide/discovery-and-setup)，配置主模型、向量模型、视觉模型及应用要求的工具。图片生成和文档转换等能力还需要相应服务。

1. **打开标书助理。** 在 Bosi 的**发现与添加 → 应用**中打开已就绪的 Bid Studio，上传招标文件并说明本次目标。来源支持 PDF、Word 和 Excel 等常用文档。
2. **确认项目配置。** 核对项目名称、工程／货物／服务分类、技术／商务编写范围、目标页数、明暗标和版式，点击**确认并创建项目**。需要使用企业资料时，明确选择投标主体。
3. **检查资料与目录。** 在工作台确认资料解析结果，对照原文检查项目事实、评分要求和材料义务，再确认章节安排与编写思路。
4. **编写与修改。** 指定要完成的章节或商务材料。技术章节可以逐章推进，也可并行安排独立章节；需要补充时直接说明保留和修改的范围。商务材料完成后检查独立审校结果。
5. **复核并导出。** 检查正文、企业证据、配图和要求覆盖，下载后打开实际文件核对标题、表格、图片与分页。缺章时可导出已有有效正文，并查看缺项提示。

第一次可以先完成目录和一章正文，例如：

> 请根据这份招标文件准备技术标。先让我确认项目配置，再完成解读和目录；目录确认后，只编写“施工组织与部署”这一章，完成后停下来让我复核。

将章节名称替换为实际目录。也可以只要求解读或目录，按当前需要逐步推进。

## 企业资料与辅助工具

- **公司资产库**：按公司整理资质、人员、业绩、财务与证明原件，供不同项目复用。导入结果需要核对；明确投标主体后再采用对应证据。
- **图片库与创作中心**：使用项目图片和组织图库，按配置生成配图；制作进度计划、甘特图、网络图和场地图示等辅助内容。素材保存后，还需检查是否已插入目标正文。
- **标书查重**：独立比较 2–6 份文档的文本、图片与属性，记录人工复核并导出报告。相似片段用于辅助检查；扫描件缺少可提取文本时，不能据此判断为零重复。

## 与项目任务协作

标书项目关联 Xpert 平台项目，集中保存资料、配置、目录、正文与执行记录。应用把业务阶段和章节工作同步到平台任务，团队可通过任务列表、甘特图和状态看板查看进度、依赖、负责人及执行尝试；内容修改和结果确认仍在标书业务流程中完成。

切换已有项目或选择项目类型，参见 ChatKit 的[项目与项目类型选择](/zh-Hans/ai/chatkit/chatkit-projects)。应用如何复用平台协作能力，参见[插件应用与项目](/zh-Hans/ai/projects/plugin-apps/index)。

<Note>
导出成功表示取得了当前文件，递交前仍需核对资料真实性、必要签章和实际附件。技术暗标或招标要求分卷时，应保留对应分卷；目标页数也需以最终排版检查为准。
</Note>
