本栏目逐个收录 Xpert 官方经典应用的产品文档。每款应用以独立产品分组呈现，围绕业务用途、首次使用、日常操作和交付结果组织内容。

实际可用应用请在当前组织的**发现与添加 → 应用**中查看；文档收录与环境中已安装的应用分别管理。

## 已收录应用

| 应用 | 适用工作 |
| --- | --- |
| [Bid Studio 标书应用](./bid-studio/index) | 工程、货物和服务类投标中的技术标、商务标与联合编制，配套企业资料、图件和查重 |
| [Code Review 代码审查](./code-review/index) | GitHub PR 差异与 AI 审查、确认提交和按仓库自动审查 |
| [Maps 地图](./maps/index) | 地点搜索、地图探索、步行与驾车路线，以及对话中的地点引用 |
| [Sites 站点](./sites/index) | 通过对话制作静态站点，预览和管理版本，按访问范围发布与分享 |

每款应用各用一篇产品文档介绍核心能力、使用流程和适用范围，可从上表或侧栏的独立分组进入。

## 阅读一款应用时关注什么

产品介绍说明适用角色、业务问题、输入与产出；快速开始带你完成第一个真实任务。业务操作指南进一步说明各阶段的状态、人工确认位置、失败后的处理方式，以及成果如何保存和再次访问。

不同应用的流程会有所不同。工作台截图、输入示例、项目类型、任务状态及导出方式，应以该应用自己的文档为准。需要管理员参与的步骤会在使用前准备中说明。
