本体空间是检查已发布语义的运行时界面。它会归组展示本体定义、本体自有数据、关联业务对象和按项目分区的图谱，帮助用户确认哪些内容已经可以用于搜索、助手推理和插件消费。

修改定义应使用本体工作室；本体空间用于回答：**当前激活的是哪个语义版本、有哪些对象、对象如何连接、这次结果由哪个准确快照支撑？**

## 界面布局

页面包含三个工作区域：

| 区域 | 用途 |
| --- | --- |
| 资源导航 | 归组并筛选本体定义、本体自有数据、关联资源和分区 |
| 搜索与图谱 | 跨有效实体搜索、检查当前实例图谱并查看快照历史 |
| 本体助手 | 携带所选定义、资源、分区、快照、图版本、实体和搜索词进行问答 |

资源面板和助手面板都可以收起。助手面板支持调整宽度，并在浏览器中记住设置。

## 汇总与健康状态

顶部汇总当前组织的数据：

- 本体定义数；
- 本体自有数据数；
- 业务对象数；
- 缺失快照的资源数；
- 快照失败的资源数；
- 总节点数与 RDF 三元组数。

每个资源或分区会显示以下健康状态：

| 状态 | 含义 | 建议处理 |
| --- | --- | --- |
| `ready` | 发布和运行时投影均可用 | 检查、搜索或消费图谱 |
| `pending` | 发布或投影仍在处理 | 等待后刷新 |
| `publish_failed` | 本体发布失败 | 检查源同步或发布错误 |
| `projection_failed` | 已有快照，但运行时投影失败 | 在 Agent 使用前修复或重跑投影 |
| `missing_snapshot` | 没有当前快照 | 发布定义或同步资源 |

<Tip>
资源可见不等于已经可以被 Agent 或插件使用。排查搜索或 Action 发现前，先确认健康徽标和当前快照。
</Tip>

## 资源归组

当资源带有本体定义引用时，导航会按本体定义归组。一个分组可以包含：

- 本体定义资源本身；
- 随定义发布的本体自有数据；
- 引用该定义的业务对象或资源；
- 按分区发布的图谱，例如特定项目的业务对象子图。

没有定义引用的资源会显示在**未关联本体定义**下。通过这个区分，可以把人工设计的领域本体与适配器生成或遗留资源图谱分开检查。

资源搜索可以匹配定义名称、业务对象类型与业务键、描述、资源 ID、所有者、版本、资源类型或标签，也可以按资源类型和健康状态筛选。

## 全局实体搜索

可以按以下字段跨资源搜索有效实体：

- 显示名称；
- 外部键；
- 别名；
- 实体类型。

还可以使用实体类型或资源类型缩小范围。结果包含匹配字段、资源与分区、实体类型编码、外部键和图谱引用。选择结果后，页面会切换到对应资源图谱，并把该实体加入助手上下文。

搜索结果有数量上限。如果宽泛查询达到上限，应缩小关键词或增加实体类型筛选，而不是把结果当作完整导出。

## 实例图谱

选择一个 `ready` 资源或分区，打开**实例图谱**。图谱会展示：

- 作为节点的实体实例；
- 作为边的关系实例；
- 类型化属性和身份字段；
- 源端点、目标端点和方向；
- resource、snapshot、graph version、ontology 与 partition 引用；
- 已注册时使用资源专属可视化。

选择实体后可以查看详情，并把它交给本体助手。图谱是快照视图：它描述已发布语义状态，不会修改工作室草稿或源系统。

底层图模型详见[实体、关系、属性图谱](./entity-graph)。

## 快照历史

为所选资源或分区打开**快照历史**。最近 30 条记录会展示：

- 源数据版本；
- 是否为当前快照；
- 发布和投影健康状态；
- 创建时间；
- graph version；
- 实体数、关系数和三元组数。

快照历史可用于解释数量变化、复现 Agent 或插件判断，以及区分“消费者读取旧版本”和“当前发布失败”。当操作需要可复现时，下游应携带 snapshot ID 与 graph version。

## 本体助手

当前组织存在有效本体助手时，本体空间会把助手挂载在图谱旁。每次请求可以携带：

- definition ID、定义资源 ID 和语义版本；
- 所选资源和可选分区；
- snapshot ID 与 graph version；
- 业务对象类型和业务键；
- 所选实体的 ID、类型编码、外部键、名称和图谱引用；
- 当前搜索词。

因此可以直接询问：

- 哪些对象和关系解释了当前业务对象？
- 选中实体适用哪些约束或 Action？
- 当前对象与早期快照相比发生了什么变化？
- 哪个来源或证据支撑这个属性？

助手严格使用当前组织范围，并依赖管理员初始化。如果没有有效助手或 ChatKit frame，页面会显示配置提示，不会静默回退到其他组织或 tenant 的助手。

## 删除本体实例或分区

本体空间支持显式删除运行时实例：

- 删除**分区**会清理该项目子图的快照历史、实体、关系、查询缓存和 RDF 图；
- 删除**资源实例**会归档资源，并清理其运行时快照、实例投影、查询缓存和 RDF 图。

统一本体定义和其他项目分区不会被删除。操作前的确认窗口会说明准确目标与影响。

<Warning>
删除运行时实例不同于在本体工作室删除或归档本体定义。继续前请确认所选 resource ID 和 partition key。
</Warning>

## 验收清单

发布或同步资源后，建议确认：

1. 资源出现在预期的本体定义分组中；
2. 健康状态为 `ready`，并存在当前快照；
3. 节点数、关系数和三元组数符合预期；
4. 可以按名称或外部键找到一个已知对象；
5. 对象图谱包含预期类型关系和属性；
6. 快照历史显示正确源版本与 graph version；
7. 助手可以获得所选对象，无需用户再次描述对象身份；
8. 下游插件会固定并重新校验资源、实体类型、快照和图版本上下文。
