数据源是语义模型访问数据库或 XMLA 服务的连接定义。数据分析页面不会把凭据写进模型；模型只保存数据源引用、目录和数据立方体信息。

## 页面结构

打开 **数据智能 → 数据源** 后，页面分为两个区域：

- **已授权**：当前工作区已经绑定、可以创建模型的连接。
- **组织可用**：组织管理员提供但尚未绑定到当前工作区的连接，点击 **绑定** 后才会出现在已授权区域。

顶部搜索会同时筛选名称、类型和连接方式。卡片上的编辑、复制、解绑和删除操作取决于当前权限。

## 新建数据源

1. 点击 **新建**，选择系统返回的数据源类型。
2. 填写名称、认证方式和动态配置字段。字段由数据源类型的字段定义生成，具体项以当前页面为准。
3. 点击 **测试连接**。测试草稿不会保存连接；编辑已有数据源时会测试当前版本。
4. 连接测试成功后点击 **保存**，然后在列表中确认数据源状态。

不要把密码、令牌或私钥写进描述字段；使用数据源表单的认证字段或平台密钥管理。

## 绑定组织数据源

在“组织可用”区域点击 **绑定**。绑定只建立工作区与组织数据源的关系，不会复制数据源配置。需要解除使用时点击 **解绑**；如果仍有模型引用，页面或系统会返回依赖错误，应先迁移模型。

## 目录和结构信息

创建模型时，目录选择器会调用数据源的目录服务：

- SQL 数据源通常返回数据库/结构和表目录。
- XMLA 数据源返回远程目录；导入数据立方体时还会发现维度、层次、层级、度量和变量。

目录为空时不要手填一个猜测值。先在数据源卡片编辑配置并连接测试，再刷新目录；连接服务或权限不足也会导致目录加载失败。

## 常见问题

| 现象 | 检查顺序 |
| --- | --- |
| 连接测试超时 | 主机/端口、网络白名单、TLS 和凭据；确认系统服务能访问目标数据库。 |
| 连接测试成功但目录为空 | 检查账号是否有结构信息权限，重新刷新目录；XMLA 还要确认目录名。 |
| 数据源不能绑定 | 检查工作区权限和组织数据源是否仍处于可用状态。 |
| 删除被拒绝 | 先在语义模型列表中确认没有模型引用该数据源。 |

数据源准备好后，继续[创建和管理语义模型](./semantic-model/manage-semantic-model)。
