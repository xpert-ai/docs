本页带你完成一条最小闭环：**绑定数据源 → 创建模型 → 配置一个可查询的数据立方体 → 校验并发布 → 执行查询**。示例值只用于演示，请替换为工作区实际值。

## 前置条件

- 已登录系统，并进入目标人工智能工作区。
- 已在组织中创建数据源，或拥有新建数据源所需的连接信息。

## 1. 准备数据源

1. 在工作区侧栏的 **数据智能 → 数据源** 打开数据源页面。
2. 如果“组织可用”列表已有连接，点击 **绑定**；否则点击 **新建**，选择系统提供的连接类型，填写名称和动态配置字段。
3. 在保存前点击 **测试连接**。成功后再保存；连接失败时先检查主机、端口、凭据和网络策略。
4. 确认数据源出现在“已授权”区域。只有已授权的数据源才能被语义模型引用。

详细字段说明见[数据源](./data-sources)。

## 2. 创建语义模型

1. 打开 **数据智能 → 语义模型**，点击 **创建**。
2. 关系型数据库选择 `SQL`；远程多维分析服务（XMLA）选择 `XMLA`。
3. 选择数据源。目录下拉框会从数据源实时加载数据库、结构和目录；XMLA 服务还会返回可用的数据立方体。
4. 填写模型名称（必填），按需填写标识、描述和目录/数据立方体，提交创建。
5. 打开新模型进入工作台。模型初始状态是 `草稿`，已发布版本号为 0。

XMLA 服务可以从数据源卡片进入 **导入数据立方体**，先发现远程结构信息，再选择一个目录和数据立方体创建模型；参见[XMLA 多维模型](./semantic-model/mdx-multidimensional-model)。

## 3. 在工作台配置最小模型

关系型模型按下面顺序操作：

1. **数据源浏览器**：点击刷新结构信息，搜索并展开结构、表和列；在预览页确认能够读取数据。
2. **数据立方体**：新增或选择数据立方体，设置事实表；至少添加一个度量并填写源列和聚合方式（通常为 `sum`）。
3. **维度**：新增维度、层次结构和层级，填写维度表、主键/外键和层级列。
4. **计算**：需要派生值时新增计算成员，填写名称、所在维度和表达式。
5. 工作台会自动保存草稿。顶部状态显示“已同步”后再继续发布。

这些区域的字段和校验规则见[语义模型工作台](./semantic-model/semantic-modeling-workspace)、[维度设计](./semantic-model/dimension-designer/dimension-designer)和[数据立方体与度量](./semantic-model/multidimensional-dataset-designer/multidimensional-dataset-designer)。

## 4. 校验并发布

1. 打开工作台的 **模型质量**，点击 **验证**。
2. 修复所有 `错误`。常见阻塞项包括：没有数据源、没有数据立方体、没有事实表、没有度量、层级没有源列、计算成员没有表达式。
3. 在 **运行与缓存** 中执行一次查询探测，确认连接服务和结构信息可用。
4. 点击顶部 **发布**，填写发布说明并选择业务域（如页面要求）。发布成功后状态变为 `已发布`，并生成新的已发布版本号。

发布创建的是固定版本；继续编辑只会修改草稿，必须再次发布才会影响下游查询。

## 5. 执行第一次查询

1. 打开 **数据智能 → 查询分析**。
2. 选择刚发布的模型和查询语言：SQL 模型使用 SQL，XMLA 模型使用 MDX。
3. 点击 **模板** 生成最小语句，替换表、列或数据立方体名称后点击 **运行**；也可以在编辑器中按 Ctrl/⌘+Enter。
4. 结果区域会显示行数、数据源编号和表格结果；右侧“最近运行”保留当前会话最近十次成功或失败记录。

查询语法和限制见[查询工作台](./semantic-model/query-lab)。

## 6. 验收清单

- [ ] 数据源在“已授权”区域，连接测试成功。
- [ ] 模型状态为“已发布”，且已发布版本号大于 0。
- [ ] 模型质量没有阻塞错误，“运行与缓存”中的查询探测成功。
- [ ] 查询结果显示预期列和行数。

如果查询失败，请先确认所选模型已发布、语言与模型类型匹配、SQL 中的表或列或 MDX 唯一名称来自当前模型结构信息。更完整的定位步骤见[查询排障与运行记录](./semantic-model/query-log)。
