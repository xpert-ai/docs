打开 **数据智能 → 语义模型**。页面会列出当前工作区可见的模型卡片，并显示名称、标识、数据源、类型、目录、状态和已发布版本。

## 创建模型

1. 点击 **创建**，先选择 `SQL`（关系型）或 `XMLA`（远程多维数据服务）。
2. 在表单填写名称和数据源；标识、描述、目录和数据立方体可选，但发布前必须能解析实际结构。
3. 目录字段会按数据源加载选项。不要把 SQL 结构名称填到 XMLA 数据立方体字段，二者来自不同结构信息服务。
4. 保存后点击模型卡片上的 **打开工作台**。

如果数据源类型是 XMLA，也可以从数据源卡片点击 **导入数据立方体**，先执行发现，再从返回的目录/数据立方体列表中选择要导入的对象。

## 搜索和编辑

搜索框匹配模型名称、标识、描述、目录和数据立方体。卡片上的 **编辑** 只修改模型基本信息；结构内容请在工作台修改。草稿编辑在工作台自动保存，列表刷新后仍可看到最新草稿状态。

## 发布和版本

发布前在工作台模型质量中修复错误、在“运行与缓存”中执行查询探测。点击 **发布** 后可填写发布说明，并在需要时选择业务域。发布成功后：

- 状态变为“已发布”；
- 已发布版本号从 0 或上一版本递增；
- 查询和指标执行使用这次发布的快照；
- 后续编辑只进入新的草稿，必须再次发布。

## 删除和访问

删除模型会经过确认。已发布模型或仍被指标引用时，系统可能拒绝删除；先迁移下游引用。访问控制区域显示业务域继承的成员和已认证指标，不再依赖旧版的“模型成员列表”配置。

需要理解工作台内部对象时，参见[语义模型与核心对象](./multidimensional-model-introduction)。
