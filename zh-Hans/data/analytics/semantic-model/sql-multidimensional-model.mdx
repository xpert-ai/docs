`SQL` 类型模型把关系型数据源的表和列组织为可管理的数据立方体。模型工作台负责建模，查询工作台负责执行只读 SQL。

## 适用范围

适用于 PostgreSQL、MySQL、Doris 等由平台连接服务提供 SQL 连接的服务。实际可选类型和字段以数据源页面返回的系统页面提供的选项为准。

## 建模要点

- 在刷新数据源浏览器结构，并按需加载表列。
- 每个数据立方体设置事实表；每个度量绑定事实表列并选择聚合方式。
- 维度的层级列来自维度表；在数据立方体关系设置中填写事实表外键和维度主键。
- 计算成员表达式在发布前通过查询实验室验证。

模型质量提示“缺少事实表”“缺少度量来源列”或“缺少层级来源列”等错误表示结构尚未完成，不是查询语法错误。

## 查询

在查询实验室中选择 SQL 语言。先用模板或简单聚合验证连接服务，再逐步加入 JOIN、过滤、分组和排序。语句应保持只读单语句；DDL、DML 和多语句不属于查询工作台支持的范围。

发布后，查询使用已发布版本的数据立方体定义；修改草稿不会立即改变线上结果。参见[数据立方体、事实表和度量](./multidimensional-dataset-designer/multidimensional-dataset-designer)。
