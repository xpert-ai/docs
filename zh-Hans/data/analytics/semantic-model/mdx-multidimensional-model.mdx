`XMLA` 模型面向 SAP BW、Microsoft Analysis Services 等提供 XMLA 连接的远程多维分析服务。系统保留远程数据立方体的系统名称，不把它转换为本地关系表。

## 导入远程数据立方体

1. 在数据源页面创建或绑定 XMLA 数据源并连接测试。
2. 在数据源卡片上点击 **导入数据立方体**，或在语义模型创建流程选择 XMLA。
3. 执行 **发现**，从返回的目录和数据立方体列表中选择目标对象。
4. 创建模型后进入 XMLA 工作台，检查维度、层次、层级、度量和变量的绑定状态。

## XMLA 工作台

- **概览**：显示当前数据立方体与绑定摘要。
- 维度、**度量和变量**：编辑显示名称、可见性、默认值及指标可用绑定。
- **刷新预览**：对比远程结构信息变化；确认校验值后应用刷新。
- **查询验证**：使用只读 MDX 编辑器执行一次验证查询。
- 发布前必须修复 `缺失` 绑定和必填的 SAP 变量默认值。

## MDX 查询

在查询实验室选择 MDX，使用 XMLA 返回的唯一名称。例如：

```mdx
SELECT {[Measures].[Sales]} ON COLUMNS
FROM [Sales]
```

远程数据立方体的实际唯一名称可能带目录或层次路径，必须从当前结构信息中复制。原始 MDX 仍受只读和权限策略限制；业务指标则通过已发布模型和显式绑定执行。

详细指标绑定见[指标度量与 XMLA 绑定](../indicator-management/indicator-measure)。
