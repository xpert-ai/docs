从模型列表打开模型后进入工作台。顶部显示模型名称、草稿和发布状态、自动保存状态和已发布版本；右侧可打开语义模型助手。

## 工作台导航

### 数据准备

- **数据源浏览器**：刷新目录和结构信息，搜索表，查看列、数据预览和模型定义。

### 语义设计

- **维度**：新增和编辑维度、层次结构、层级及成员预览。
- **数据立方体**：选择事实表，维护事实表与维度的连接，配置度量和使用预览。
- **计算**：维护计算成员的名称、维度和表达式。

### 验证与使用

- **查询实验室**：在当前模型上下文中执行 SQL 或 MDX。
- **成员**：按模型、数据立方体、维度、层次和层级检索成员。
- **模型质量**：查看校验分数、错误/警告/提示和发布门槛。

### 治理与运维

- **访问控制**：查看业务域继承的访问成员和认证指标。
- **运行与缓存**：刷新结构信息、执行查询探测、查看运行状态和缓存策略。
- **模型设置**：编辑模型设置和偏好。

## 草稿和自动保存

关系型模型的字段修改会进入自动保存队列，顶部状态可能显示“等待保存、保存中、已同步、冲突或错误”。发布、刷新、助手修改前要等到“已同步”；发生冲突时刷新模型并重新确认草稿。XMLA 模型的结构修改在其专用工作台中点击 **保存**。

## 推荐顺序

1. 刷新数据源浏览器并确认表/列。
2. 为数据立方体绑定事实表和度量。
3. 完善维度主键、外键、层次和层级。
4. 添加必要的派生表达式。
5. 在模型质量中验证，再到“运行与缓存”中执行查询探测。
6. 发布，随后在查询实验室验证真实结果。
