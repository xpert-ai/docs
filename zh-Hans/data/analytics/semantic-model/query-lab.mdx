打开 **数据智能 → 查询分析**，或在模型工作台进入 **查询实验室**。页面加载当前工作区可见的语义模型；没有可用模型时必须先创建并授权模型。

## 查询步骤

1. 在模型下拉框选择模型。
2. 选择查询语言：关系型模型使用 **SQL**，XMLA 模型使用 **MDX**。
3. 点击 **模板** 生成当前类型的示例；根据数据源浏览器/结构信息中的实际名称修改语句。
4. 点击 **运行**，或在查询编辑器按 Ctrl/⌘+Enter。
5. 在结果区域检查行数、数据源编号、列和数据；失败时读取红色错误信息并回到模型结构信息修正名称或绑定。

SQL 示例（关系型模型）：

```sql
SELECT customer_id, SUM(amount) AS total_amount
FROM sales
GROUP BY customer_id
ORDER BY total_amount DESC
LIMIT 20
```

MDX 示例（XMLA 模型，唯一名称必须来自当前数据立方体）：

```mdx
SELECT {[Measures].[Sales]} ON COLUMNS
FROM [Sales]
```

## 查询限制

查询服务只接受一条只读语句。SQL 由数据源连接服务执行；XMLA 的 MDX 由 XMLA 连接服务执行。不要在 XMLA 模型上切换到 SQL，也不要把表名 SQL 语法用于 MDX。

## 结果和最近运行

当前工作台会话右侧显示最近十次运行，记录模型、语言、语句、成功/失败、耗时和行数。刷新页面后这段会话记录不会作为页面保留；系统仍会为查询写入查询运行记录，记录核对/运维需要查看对应的运行记录或服务日志。

## 常见失败

| 错误方向 | 处理 |
| --- | --- |
| 没有可选模型 | 回到语义模型列表，确认模型已创建且当前账号有查看权限。 |
| 语言与模型类型不匹配 | 按模型类型选择 SQL 或 MDX。 |
| 表、列或数据立方体不存在 | 在工作台的数据源浏览器、数据立方体或 XMLA 结构信息中复制准确名称。 |
| 发布模型查询失败 | 在“运行与缓存”中重新执行查询探测；检查数据源网络和凭据。 |

需要查看后台记录时参见[查询排障与运行记录](./query-log)。
