查询工作台右侧的“最近运行”只保留当前页面会话最近十次记录。系统还会为每次查询保存运行记录，包括数据源、查询语言、语句、状态、耗时、行数和错误信息；当前数据分析页面没有单独的历史列表。

## 按顺序排查

1. **访问权限**：确认账号可以查看模型并执行查询，模型所在业务域也允许访问。
2. **模型状态**：模型必须有可用草稿；查询指标还要求模型已经发布。
3. **查询语言**：关系型模型使用 SQL，XMLA 模型使用只读 MDX。
4. **结构信息**：在数据源浏览器刷新表和列，在 XMLA 工作台刷新远程结构信息；从页面复制准确的目录、数据立方体、层次和度量名称。
5. **连接**：在“运行与缓存”中执行查询探测；失败时检查数据源连接测试、网络和凭据。
6. **草稿同步**：顶部显示冲突或错误时，先刷新并确认最新草稿，再重新保存或发布。

## 常见错误

| 现象 | 处理 |
| --- | --- |
| 没有可用模型 | 创建模型或绑定组织数据源，并确认查看权限。 |
| 查询语言不支持 | 按模型类型选择 SQL 或 MDX。 |
| 对象不存在 | 从当前结构信息或数据立方体中复制名称；XMLA 还要检查对象是否显示“缺失”。 |
| 发布被阻止 | 打开模型质量，逐条处理错误；警告也应在发布前确认。 |
| 查询超时或连接失败 | 执行查询探测和数据源连接测试，并检查系统到数据库/XMLA 服务的网络。 |

如需完整历史记录查询，请由平台运维查看系统的运行记录，不要把浏览器中的会话列表当成永久历史。
