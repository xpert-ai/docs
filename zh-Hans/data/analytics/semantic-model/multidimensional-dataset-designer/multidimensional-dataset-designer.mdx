当前数据立方体建模入口是模型工作台的 **数据立方体**。一个语义模型可以包含多个数据立方体；每个数据立方体独立配置事实表、度量、维度和计算成员。

## 配置关系型数据立方体

1. 点击 **新增数据立方体** 或选择已有数据立方体。
2. 在关系映射模式选择事实表；事实表是查询聚合的起点。
3. 添加度量，填写名称、显示名称、源列、数据类型、聚合方式（如 `sum`）和格式字符串；每个数据立方体至少需要一个度量。
4. 添加维度并设置事实表外键、维度表和主键。
5. 在“语义设计”模式检查度量与维度的语义字段。
6. 在使用预览查看对外暴露的字段，并打开查询实验室做真实查询。

## 计算成员

在 **计算** 中新增计算成员，填写名称、所在维度（通常为“度量”维度）和表达式。空表达式会被模型质量标记为错误；复杂表达式先在查询实验室验证。

## XMLA 数据立方体

导入 XMLA 数据立方体后，数据立方体、度量和维度的远程绑定由结构信息生成。可以在 XMLA 工作台编辑显示名称、可见性、变量默认值和指标绑定，但不要改写远程系统名称来“修复”缺失对象；应先刷新预览确认远程模型变化。

## 发布前检查

- 事实表和每个关系键都存在；
- 至少一个度量，且每个度量有源列（关系型）或有效的远程绑定（XMLA）；
- 每个维度至少一个层次和层级；
- 计算成员有表达式；
- 模型质量无阻塞错误，“运行与缓存”中的查询探测成功。
