在 **数据智能 → 指标管理** 点击 **新建** 或行上的编辑按钮。当前编辑器是对话框，不支持旧版 YAML 批量注册流程。

## 基础字段

| 字段 | 说明 |
| --- | --- |
| 编码 | 工作区内用于识别指标的稳定代码，必填。 |
| 名称 | 展示名称，必填。 |
| 类型 | `基础指标（BASIC）` 或 `派生指标（DERIVE）`。 |
| 模型 | 绑定的语义模型；建议选择已发布模型。 |
| 描述 | 指标口径说明。 |
| 业务定义 | 面向业务用户的定义。 |
| 负责人/有效期 | 负责人和有效期，可选。 |

## 基础指标（BASIC）

选择 XMLA 模型后，编辑器会从数据立方体加载可用度量、层级、变量和时间粒度。选择一个度量，按需添加维度绑定、过滤器、变量和时间维度。

## 派生指标（DERIVE）

派生指标可填写公式；XMLA 模型使用受限制的 MDX 值表达式，必须引用至少一个现有度量，不能提交完整 `SELECT`、注释或修改语句。关系型模型的草稿仍会保存公式和过滤定义，执行能力以当前系统的校验结果为准。

## 保存、发布和删除

保存只更新草稿。回到列表可以按名称、编码和描述搜索，并按草稿/已发布/已归档筛选。发布会执行模型绑定、度量、维度和过滤器校验；删除会经过确认，已发布或被下游引用时可能被系统阻止。
