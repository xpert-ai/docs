在指标列表中点击 **查询**。系统会读取指标发布快照和绑定的语义模型，生成 SQL 或 MDX 查询，并返回规范化结果。

## 执行前提

- 指标状态为“已发布”；
- 绑定模型状态为“已发布”，且包含指标引用的数据立方体和度量；
- XMLA 指标的变量、维度和过滤器绑定均为有效。

## 结果内容

结果窗口显示指标名称、编码、模型版本、数据立方体、度量/表达式、语言以及表格结果。系统响应还包含实际生成的 `sql` 或 `mdx`，便于核对和排查；用户输入的变量、过滤器、时间粒度会显示在执行上下文中。

## 失败处理

| 现象 | 处理 |
| --- | --- |
| 指标仍是草稿 | 回到列表点击发布，先修复发布校验错误。 |
| 模型版本不匹配 | 在模型工作台重新发布，并检查指标是否引用已存在的数据立方体。 |
| XMLA 度量或层级缺失 | 刷新 XMLA 结构信息，修复指标绑定后重新发布。 |
| 必填变量缺失 | 在指标查询时输入变量，或给模型变量设置默认值。 |

指标查询是按指标规则执行的只读查询，不提供任意 SQL/MDX 编辑；需要探索性查询请使用[查询工作台](../semantic-model/query-lab)。
