这条路径面向第一次使用 Data Xpert 的管理员、建模人员和 Agent 构建者。你将完成一条只读闭环：**选择工作空间 → 接入资源 → 同步本体 → 搜索实体 → 发现并执行只读 Action → 查看审计**。

## 先选择要完成的业务任务

如果你的目标是快速理解系统，可以直接从业务问题进入：

| 你想完成的事情 | 从这里开始 |
| --- | --- |
| 查询销售额、订单量或采购趋势 | [语义分析实践](../practices/semantic-analysis) |
| 接入 SAP、数据库或知识库 | [资源接入](../features/control-plane/resource-access) |
| 统一客户、订单或设备等业务对象 | [本体工作室](../ontology/ontology-studio) |
| 让助手查询数据、生成看板或准备工单 | [Action 发现](../features/agent-execution/action-discovery) 或[业务应用](../apps/index) |
| 控制高风险操作并追溯结果 | [策略](../features/governance/policies) 和[执行审计](../features/governance/audit) |

第一次体验建议从一个只读问题开始，例如：“请告诉我本月采购订单数量、供应商数量和产品分布，并说明数据来源和更新时间。”系统会把业务问题映射到已授权资源中的实体和 Action，再返回结果与审计信息。更多场景见[按业务场景选择](./roles)。

## 1. 登录并选择工作空间

登录 Data Xpert 后，确认当前组织和 AI 工作空间正确。首次使用时，请确认自己拥有以下页面的访问权限：

- **数据与本体**：资源接入、本体空间和资源对话；
- **治理**：策略、审批和执行审计；
- **工作空间数据源**：查看已授权的数据源。

如果看不到目标工作空间或数据源，请联系组织管理员完成授权，再继续后面的步骤。

## 2. 接入一个资源

如果工作空间已经有可用资源，可直接进入资源详情；否则在**数据与本体 → 资源接入**点击**新注册外部资源**：

1. 选择资源类型，填写资源标识、负责人和版本信息。
2. 从**密钥管理**选择连接引用，完成该资源类型要求的能力配置。
3. 创建资源并打开资源详情。

连接信息应通过 Secret 管理，页面和文档中不要填写密码、token 或证书内容。不同资源类型的字段说明见[资源接入控制面](../features/control-plane/resource-access)。

## 3. 同步并发布本体

在资源详情的**同步作业**中执行**全量同步**。等待作业完成后，确认详情中出现当前 `snapshotId`、实体数或关系数。

首次接入建议先使用全量同步；资源稳定运行后，再根据需要使用增量同步。同步失败时，先查看作业的错误信息，再按[同步失败](./troubleshooting#同步作业失败)处理。

## 4. 搜索实体并查看上下文

进入**数据与本体 → 本体空间**，找到刚同步的资源。确认健康状态为 `ready`，然后按实体类型、名称或外部键搜索一个对象，打开它的实体图谱或邻域信息。

你应能看到实体类型、属性、关系、来源和当前本体快照。若资源仍处于 `missing_snapshot`、`pending` 或 `projection_failed`，先回到资源详情处理同步或发布问题。

## 5. 发现并执行只读 Action

在资源对话或已配置的 Agent 工作台中，先让助手说明当前资源和实体上下文，再要求发现可用 Action。例如：“查找该资源中可查询的销售实体，并说明将使用的 Action。”

按以下顺序操作：

1. 发现 Action，确认目标实体类型和允许的操作。
2. 模拟一个低风险查询，检查参数、策略和运行状态。
3. 模拟成功后执行只读 Action，查看返回结果或工作台内容。

技术集成可依次调用 `discoverActions`、`simulateAction` 和 `executeAction`。写入、高风险或需要审批的 Action，应先阅读[审批](../features/governance/approvals)，不要在首次使用中直接执行。

## 6. 查看执行审计

进入**治理 → 执行审计**，按资源、Action 或任务筛选刚才的调用。确认记录包含调用者、目标实体、本体快照、策略决定、执行状态和结果摘要。

审计记录应能够回答“谁基于哪个快照调用了什么 Action、为什么允许以及结果是什么”。

## 完成检查

- [ ] 已选择正确的组织和 AI 工作空间。
- [ ] Resource 出现在当前组织的资源接入列表。
- [ ] 首次全量同步已完成，并生成 `snapshotId`。
- [ ] 本体空间健康状态为 `ready`，实体图谱可以搜索。
- [ ] 只读 Action 经过发现和模拟后成功执行。
- [ ] 执行审计记录了调用、策略结果、本体快照和结果摘要。

下一步：管理员阅读[资源接入控制面](../features/control-plane/resource-access)，建模人员阅读[本体工作室](../ontology/ontology-studio)，Agent 构建者阅读[Action 发现、模拟与执行](../features/agent-execution/action-discovery)，治理人员阅读[执行审计](../features/governance/audit)。
