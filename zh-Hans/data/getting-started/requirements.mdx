## 账号与工作空间

准备一个可以登录 Data Xpert 的账号，并确认：

- 当前组织是目标组织；
- 已进入要操作的 AI 工作空间；
- 工作空间可以访问至少一个数据源或外部资源；
- 你知道该工作空间使用的 Assistant（如果要通过 Agent 工作台操作）。

组织可用不等于工作空间可用。如果看不到资源或数据源，请让管理员完成工作空间授权。

## 数据源与资源

快速开始需要一个可访问的数据源或已经注册的外部资源。可以使用工作空间已有的语义模型、数据库、SAP OData 或知识资源。

如果没有现成资源，请由管理员先完成[资源接入](../features/control-plane/resource-access)，包括资源类型、连接引用和能力配置，再回到[快速开始](./index)执行同步。

## 账号权限

首次配置建议由管理员完成，之后再按角色分工：

- **管理员**：注册资源、管理 Secret、执行同步和查看审计；
- **建模人员**：编辑、校验和发布本体；
- **Agent 构建者**：使用 Assistant、Agent Tools 和工作台；
- **治理人员**：配置策略、处理审批和复盘审计；
- **只读使用者**：搜索本体实体并执行低风险查询。

Action 仍须经过发现、模拟、策略检查和审计。不要为了让操作成功而授予任意后端接口权限。

## Secret 与连接引用

资源注册前，在**数据与本体 → 密钥管理**创建连接 Secret，并在资源配置中使用页面生成的连接引用。Secret 中的地址、认证信息和证书应指向组织允许访问的业务系统；不要把敏感值写入文档、截图或 Action 参数。

完成以上准备后，按[快速开始](./index)完成第一次资源同步和只读查询。
