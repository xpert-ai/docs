Member retrieval confirms that a dimension level returns real values and helps you copy accurate unique names for MDX and metric filters. The current page provides a limited member list and preview inside the workspace.

## Where to use it

- **Data source browser → Preview**: load a live sample for a fact table or member target.
- **Members** in the model workspace: search model members. Results include the cube, dimension, hierarchy, level, unique name, identifier, display name, and whether a retrieval index exists.
- XMLA metric editor: choose dimension bindings and member filters from the levels available in the current cube.

## Steps

1. Refresh the model structure so table and level information is current.
2. Open **Members** and search by keyword. If there are no results, check that the model is published and the level has queryable members.
3. Copy the returned unique name for MDX or metric filters. Do not copy only the display name.
4. For relational dimensions, click **Reload** in the data source browser preview. If preview fails, check data source permissions and column mappings.

When there are many members, the page returns a limited result set. Narrow the search with a keyword and level; the member list is not a full export.
