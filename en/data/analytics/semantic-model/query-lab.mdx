Open **Data Intelligence → Query Analysis**, or enter **Query lab** from a model workspace. The page loads semantic models visible to the current workspace. Create and authorize a model first if none is available.

## Query steps

1. Select a model from the model list.
2. Choose the query language: **SQL** for relational models or **MDX** for XMLA models.
3. Click **Template** and replace names with values from the data source browser or current structure information.
4. Click **Run**, or press Ctrl/⌘+Enter in the query editor.
5. Check the row count, data source identifier, columns, and data in the result area. If it fails, read the error and correct the name or binding in the model structure.

SQL example:

```sql
SELECT customer_id, SUM(amount) AS total_amount
FROM sales
GROUP BY customer_id
ORDER BY total_amount DESC
LIMIT 20
```

MDX example:

```mdx
SELECT {[Measures].[Sales]} ON COLUMNS
FROM [Sales]
```

## Query limits

The query service accepts one read-only statement. SQL runs through the data source connection service, and XMLA MDX runs through the XMLA connection service. Do not use SQL on an XMLA model or SQL table syntax in MDX.

## Results and recent runs

The right side of the workspace shows the latest ten runs for the current session, including model, language, statement, success or failure, duration, and row count. Refreshing the page clears this session list. The system still records query runs for operational review.

## Common failures

| Problem | What to do |
| --- | --- |
| No model is available | Return to the semantic model list and confirm that the model exists and you have view permission. |
| Language does not match the model | Choose SQL or MDX according to the model type. |
| Table, column, or cube does not exist | Copy the exact name from the data source browser, cube, or XMLA structure. |
| A published model query fails | Run a new query probe in **Run and cache**, then check the data source network and credentials. |

See [Query troubleshooting and run records](./query-log) for more help.
