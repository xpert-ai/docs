Metric management is the workspace catalog for business metrics. Open it from **Data Intelligence → Metric Management**. It packages measures or MDX expressions from semantic models into reusable, traceable metrics.

## Lifecycle

    Create draft → edit definition → optional certification → publish → query or use with the assistant

Metric status is **Draft**, **Published**, or **Archived**. Certification is a separate state: publishing makes a metric executable, while certification confirms that its business definition has been reviewed.

## Metric types

- **Basic metric (BASIC)**: binds to one model measure and can define dimensions, variables, filters, units, and aggregation.
- **Derived metric (DERIVE)**: calculates a value from model measures or an MDX value expression. An XMLA expression must reference an existing measure.

## Recommended flow

1. Publish a queryable semantic model.
2. Click **New** in the metric list and enter the code, name, description, and model.
3. Configure the basic or derived definition, free dimensions, variables, and filters.
4. Save the draft. A user with metric certification permission can certify it when required.
5. Click **Publish**. A successful check changes the metric status to **Published**.
6. Click **Query** to verify the result. Both the metric and its model must be published.
