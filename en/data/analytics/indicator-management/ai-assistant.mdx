There is no separate page for the old /analysis command inside a metric page. Open the assistant from the semantic model workspace. It can read the current model, cube, selected object, and model quality summary to help check the measures, levels, and variables needed by a metric.

## Recommended flow

1. In the model workspace, open **Members** or **Cube** and select the measure or level to bind.
2. Ask the assistant to explain the unique name, suggest a basic or derived metric, or create a read-only validation query.
3. Confirm the fields manually in the metric dialog and save the draft.
4. Publish the model and metric, then click **Query** to verify the definition with a real result.

Review any expression and filter suggested by the assistant. It cannot bypass metric publishing checks, certification, or business-domain permissions, and it never turns a draft into a published asset automatically.
