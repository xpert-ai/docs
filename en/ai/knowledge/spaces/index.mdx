title: "Spaces"
description: "Maintain shared pages, files and results with people and multiple Assistants in one project."
---

**Spaces** gives teams and Assistants a place to maintain content beyond a single chat. Start a page, import material, upload attachments or collect generated results, then return to the same content to improve and reuse it.

Use it for project manuals, team guides, research notes, draft proposals and evolving reports.

## What you can do

| Capability | Workflow |
| --- | --- |
| Create and organize | Create pages and folders, upload files, search lists and view recent updates |
| Edit together | Edit Markdown text, tables, formulas and resource references, with collaborator presence |
| Work with AI | Send a document or selection to an Assistant, generate content and review proposed changes |
| Import and collect | Import authorized external text copies and collect accessible result versions |
| Search and reuse | Enable the project knowledge base and retrieve saved content after indexing |

## How a space organizes content

A space is based on a project of type Collaborative space. Multiple Assistants connected to that project share its pages and files. The project also manages members and roles. An Assistant's personal file settings do not create personal copies of project content.

Page text is stored in project Markdown files. Spaces provides organization and entry points; editing a particular file format depends on installed editors. Spreadsheet editing can be added through Office Editor. Other formats depend on the available capabilities.

## Get started

Follow the [quickstart](./quickstart) to create a page and verify it is saved. Continue with [content organization](./organizing-content), [editing and collaboration](./editing-and-collaboration) and [writing with Assistants](./assistant-writing).

Spaces requires compatible platform, Spaces and Markdown editor installations, plus an enabled, published Assistant connected to the project. Available entry points depend on deployment and access.

## Access

Owners and administrators manage the project, editors modify content, and ordinary members have read access. Archived projects are read-only. Access to an Assistant does not grant membership in every project it connects to. See [Members and permissions](../../projects/setup/members-and-permissions).

Full-text retrieval requires enabling the project knowledge base. External imports create local copies and do not automatically synchronize changes. See [Search and reuse](./search-and-reuse) and [Document imports](./document-import).
