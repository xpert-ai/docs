---
title: "Writing with Assistants"
description: "Give instructions about the current page, review AI suggestions and retain traceable content."
---

Open the page in Spaces. To change existing content, click **Review in Assistant** in the editor toolbar, describe the goal in the assistance field and send it to the Assistant. The request includes the current document and asks the Assistant to read its latest content before proposing changes.

If you add a document or selection through a reference action, enter and send the task separately. Adding a reference does not automatically submit a message or replace an existing composer draft.

## Give a concrete task

For example:

> Add completion criteria to the Startup checklist in this manual. Preserve the goal and order. Propose changes first and mark anything the team still needs to confirm.

Or:

> Read the project's research notes and draft a proposal summary. Cite the source material and list uncertain points separately.

Confirm that the Assistant is using the correct project and page. Different Assistants must connect to the same project to work with the same shared material.

## Review and continue

Once the proposal is ready, click **Review in Assistant** again. The proposals section displays the original text, suggested text and status. Locate the change in the document, then accept or reject it. The same panel provides comments and version recovery.

Before accepting a change, check its factual basis and scope. If another collaborator has changed the content, review the current version again. Pending proposals leave the document text unchanged.

After accepting changes, return to the page and verify its text and save state. A completion message does not prove that the page is saved. Resolve conflicts between external file changes and editor content before continuing.

## Reuse content

Reading a specified page and retrieving from a knowledge base are different workflows. For cross-document questions and full-text discovery, prepare project indexing as described in [Search and reuse](./search-and-reuse), then open the answer's sources to verify them.
