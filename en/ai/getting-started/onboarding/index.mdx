When you start an Xpert AI instance that has not been initialized, the onboarding wizard helps you create the super administrator and default organization, with an optional step for configuring the primary AI model.

<Info>
The current onboarding flow consists of a welcome page followed by three initialization steps. The legacy **Generate demo data** and **Add data source** steps are no longer part of first-time setup; you can complete those tasks after entering the platform when needed.
</Info>

## Open the welcome page

After confirming that the welcome page loads correctly, use the language menu in the upper-right corner to change the interface language. The selected language is also applied to the new administrator and default organization.

Click **Let's get started** to open the initialization wizard.

## Step 1: Create the super administrator and default organization

Enter the following information:

| Field | Description |
| --- | --- |
| First name and last name | The display name of the super administrator. |
| Email | Required. This becomes the super administrator's login account. |
| Company or team name | Required. Xpert AI uses this name to create the default organization. |
| Password and confirmation | Required. The password must contain at least eight characters, and both entries must match. |

After you click **Next**, Xpert AI initializes the tenant, creates the super administrator and default organization, adds the administrator to that organization, and signs you in automatically.

## Step 2: Configure the AI model

Use this step to configure the platform's primary AI assistant:

1. Select an AI model provider and configure its authorization information.
2. Select the default large language model.
3. Click **Save and Next**.

If model credentials are not available yet, click **Skip**. You can finish the setup later in system settings. For details, see [AI Assistant Settings](/en/ai/agent/ai-assistant/settings).

## Step 3: Complete the wizard

After saving or skipping AI model configuration, the wizard displays the completion page. Click **Take me to Xpert AI Platform** to open the chat home page.

The onboarding wizard is shown only when the system does not yet have a tenant. If initialization has already been completed, visiting the onboarding route redirects you to the platform home page.
